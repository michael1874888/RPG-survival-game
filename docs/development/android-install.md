APK 位於核准 SSD：

```text
/Volumes/Samsung SSD 990 EVO Plus 1TB/AI-Data/Artifacts/codex/RPG_Game_Dev/builds/android/bramble-v0.4-debug.apk
```

大小 37,295,556 bytes（35.6 MiB）。最新 SHA-256 及獨立簽署、Manifest 驗證結果見 [建置收據](../../tools/android-build.json)。支援目標為 ARM64、Android 7.0／API 24 或以上、OpenGL ES 3.0；實際設備相容性仍需安裝後確認。

目前已確認：org.bramble.prototype、版本 0.4.0／versionCode 4、橫向主畫面、v2／v3 簽章、沒有要求任何 Android 權限。沿用既有套件 ID 與除錯簽署身分，用於更新原型。使用者已提供 v0.4 主觀回饋，但未列明設備／平台，不將其自動記為 Android 相容性與效能驗收。

## 兩種安裝方式

**直接在手機安裝：**使用你慣用的檔案傳輸方式，將 APK 複製到 Android 手機，在檔案管理器開啟並依安裝畫面操作。這條路徑不需要 USB 偵錯。若手機顯示無法安裝，記下完整訊息再診斷。

**由 Mac 協助安裝與取得紀錄：**將手機用可傳資料的 USB 線接上 Mac；在手機開啟 USB 偵錯並確認對這台 Mac 的偵錯授權後，再檢查 adb 是否看到該裝置。若有多台裝置，先指定目標；安裝只使用本專案 APK，不自動移除既有應用。

v0.4 尚未由開發端安裝至手機。不要把 APK 匯出成功當成實機測試成功。

## v0.4 這次玩什麼

四個組合各玩一次，每次最多 45 秒；短情境能力固定、不升級，生命歸零仍可結算。建議順序：四面包圍 A → 同情境換 B → 同構築換隊列 B → 同情境換 A。結算有對應切換按鈕，回選單確認後開始，不要求通關。

觀察隊列下穿透是否更有感、是否促使改變站位／瞄準，以及反彈是否仍能取代它的用途。原本三分鐘生存與自由升級仍可選；詳細範圍與限制見陣形比較文件。

## 首次安裝或操作回歸檢查

本輪目標、通過條件與最小回饋格式見 [手機測試清單](mobile-test-checklist.md)。

1. 橫向開啟遊戲，確認文字與按鈕沒有被瀏海或螢幕邊界擋住。
2. 左手移動、右手拖曳瞄準攻擊；輪流抬起一根手指，另一根的操作應保持獨立。
3. 擊敗敵人並靠近撿經驗，升級時應暫停；選完強化後再拖曳右側開始攻擊。
4. 試一次切到背景再返回，戰鬥應保持暫停，點繼續才恢復。
5. 觀察一次失敗或三分鐘成功，確認可以重新開始，生命與本局升級已重設。

回饋先記手機型號、Android 版本，以及最明顯的一個問題：瞄準不順、手指遮擋、文字太小、升級不明顯、敵人壓力不合適或畫面卡頓。先處理實際觀察到的問題，再增加內容。

## 再次匯出

在專案根目錄執行：

```sh
python3 scripts/export-android.py
```

腳本重新核對 SSD UUID 目的地、模板雜湊，匯入專案後匯出，再獨立驗證 APK 簽署、ZIP、架構、Manifest、權限及字型授權。除錯私鑰留在內部磁碟的 Bramble 應用支援目錄，不放入 APK 或 SSD。重新匯出不會自動安裝到手機。
