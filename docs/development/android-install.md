## 兩種安裝方式

**直接在手機安裝：**使用你慣用的檔案傳輸方式，將 APK 複製到 Android 手機，在檔案管理器開啟並依安裝畫面操作。這條路徑不需要 USB 偵錯。若手機顯示無法安裝，記下完整訊息再診斷。

**由 Mac 協助安裝與取得紀錄：**將手機用可傳資料的 USB 線接上 Mac；在手機開啟 USB 偵錯並確認對這台 Mac 的偵錯授權後，再檢查 adb 是否看到該裝置。若有多台裝置，先指定目標；安裝只使用本專案 APK，不自動移除既有應用。

v0.10 已由使用者在 Android 手機實際試玩。開發端當時 adb 未偵測到連線裝置，未代為安裝；具體機型、安裝方式與更新流程未記錄。

## 首次安裝或操作回歸檢查

本輪目標與最小試玩方式見 [奈奈 v0.17 試玩說明](nana-v0.17-practice.md)。

1. 橫向開啟遊戲，確認文字與按鈕沒有被瀏海或螢幕邊界擋住。
2. 左手移動、右手拖曳瞄準攻擊；輪流抬起一根手指，另一根的操作應保持獨立。
3. 連抓命中累積三格，確認可重咬；按大絕後確認影化與冷卻顯示。
4. 試一次切到背景再返回，戰鬥應保持暫停，點繼續才恢復。
5. 觀察一次失敗或情境完成，確認重新開始後生命、重咬準備與大絕均已重設。

回饋先記手機型號、Android 版本，以及最明顯的一個問題：近戰距離、重咬時機、大絕按鍵、手指遮擋、敵人壓力或畫面卡頓。先處理實際觀察到的問題，再增加內容。

## 再次匯出

在專案根目錄執行：

```sh
python3 scripts/export-android.py
```

腳本重新核對 SSD UUID 目的地、模板雜湊，匯入專案後匯出，再獨立驗證 APK 簽署、ZIP、架構、Manifest、權限及字型授權。除錯私鑰留在內部磁碟的 Bramble 應用支援目錄，不放入 APK 或 SSD。重新匯出不會自動安裝到手機。
