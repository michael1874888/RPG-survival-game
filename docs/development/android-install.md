# Android 原型安裝與第一輪測試

更新：2026-11-20。Bramble v0.30.0（奈奈夜巡 X1），單人離線、ARM64 debug APK。正式遊戲名稱尚未決定。本輪重點見 [v0.30 試玩說明](nana-v0.30-practice.md)。

## 檔案

APK 位於核准 SSD：

```text
/Volumes/Samsung SSD 990 EVO Plus 1TB/AI-Data/Artifacts/codex/RPG_Game_Dev/builds/android/bramble-v0.30-debug.apk
```

最新大小、SHA-256 及獨立簽署、Manifest 驗證結果見 [建置收據](../../tools/android-build.json)。支援目標為 ARM64、Android 7.0／API 24 或以上、OpenGL ES 3.0；實際設備相容性仍需安裝後確認。

封裝檢查確認：org.bramble.prototype、版本 0.30.0／versionCode 30、橫向設定、v2／v3 簽章；唯一的權限是震動（VIBRATE，安裝時不會跳出詢問），可在遊戲設定關閉震動。沿用 v0.19／v0.20 的套件 ID 與除錯簽署身分，可直接覆蓋安裝；舊版取得的寶物會在第一次開啟時帶到新版。實際安裝更新與遷移仍須在手機確認。2026-11-15 使用者確認在 Android 手機試玩 v0.10，回饋整體體感 OK；機型、Android 版本及效能量測未提供。

v0.17 使用既有除錯簽署憑證，獨立驗證指紋與先前版本相同；實際更新是否成功仍以手機安裝結果為準。v0.9 至 v0.16 APK 仍保留在同一 SSD 專案目錄。已收到 v0.16 實玩回饋，本次設備與安裝方式未提供。

## 兩種安裝方式

**直接在手機安裝：**使用你慣用的檔案傳輸方式，將 APK 複製到 Android 手機，在檔案管理器開啟並依安裝畫面操作。這條路徑不需要 USB 偵錯。若手機顯示無法安裝，記下完整訊息再診斷。

**由 Mac 協助安裝與取得紀錄：**將手機用可傳資料的 USB 線接上 Mac；在手機開啟 USB 偵錯並確認對這台 Mac 的偵錯授權後，再檢查 adb 是否看到該裝置。若有多台裝置，先指定目標；安裝只使用本專案 APK，不自動移除既有應用。

v0.10 已由使用者在 Android 手機實際試玩。開發端當時 adb 未偵測到連線裝置，未代為安裝；具體機型、安裝方式與更新流程未記錄。

## v0.30 這次玩什麼

主畫面選「出發夜巡」，選區域、習性與寶物，走夜巡地圖並打倒守關。也可以先進「練習場」熟悉撲擊。詳見 [v0.30 試玩說明](nana-v0.30-practice.md)。

## 首次安裝或操作回歸檢查

本輪目標與最小試玩方式見 [奈奈 v0.30 試玩說明](nana-v0.30-practice.md)。

1. 橫向開啟遊戲，確認文字與按鈕沒有被瀏海或螢幕邊界擋住。
2. 左手移動；右手拖曳會出現撲擊線，放開才撲出，在起點附近放開則取消。輪流抬起一根手指，另一根的操作應保持獨立。
3. 夜影能量充滿後點右下按鈕，確認撲擊次數補滿、周圍敵人被震開。
4. 試一次切到背景再返回，戰鬥應暫停；選「保存並回到首頁」後再「繼續夜巡」，應回到同一場。
5. 敵人很多時注意畫面是否卡頓。

回饋先記手機型號、Android 版本，以及最明顯的一個問題：撲擊手感、手指遮擋、看不清危險、畫面卡頓或一局太長／太短。

## 再次匯出

在專案根目錄執行：

```sh
python3 scripts/export-android.py
```

腳本重新核對 SSD UUID 目的地、模板雜湊，匯入專案後匯出，再獨立驗證 APK 簽署、ZIP、架構、Manifest、權限及字型授權。除錯私鑰留在內部磁碟的 Bramble 應用支援目錄，不放入 APK 或 SSD。重新匯出不會自動安裝到手機。
