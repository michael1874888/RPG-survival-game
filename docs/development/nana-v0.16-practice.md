# 奈奈 v0.16：追擊與夾擊試玩

更新：2026-11-17。**Status:** implemented · 已收到真人試玩回饋；整局樂趣與重玩意願待確認。

使用者表示疾追者確實較有威脅性，需要走位和開大絕；未提供能力配置、終局結果、夾擊公平性或重玩意願。[回饋紀錄](../design/poc-feedback-and-followups.md#v016-追擊試玩回饋2026-11-17)。

依 v0.15 實玩回饋：敵人太容易清除、缺少追擊與腹背受敵感，大絕沒有使用時機。本版保留原有操作、能力、四段短局和易清除的普通追逐者，在四段加入疾追者，檢查是否形成值得應對的壓力。

主畫面選「森林短局 · 四段冒險」，自由選 A 或 B 開局。紅色、尖耳且頭上有淡黃色弧線的是疾追者：生命 48、速度 280，奈奈基礎速度 260。普通追逐者仍較容易清除。疾追者在每段兩個時機各以一隻由左右兩側排入；安全距離、出生預警與重新嘗試規則仍適用，玩家位置和安全位置搜尋會影響實際出現位置，不保證每次都剛好夾在兩側。

B Lv.2 的蓄勢爪與大絕能推開存活的疾追者；疾追者接觸造成 8 傷害，重咬選敵會把牠視為優先協助的特殊敵人之一。這些數值是試玩起點。段間選擇、回血與終戰維持前版規則。

建議先正常玩一輪，注意紅色疾追者出現時，是否真的需要換方向、打開缺口或決定先打哪一邊；危險是否看得懂、是否有合理退路，及大絕有沒有自然的使用時機。若太難，記下第幾段與當時狀況即可，不需一直重試。已收到上述實玩回饋；本次設備、觸控與效能未提供。

開發端 310 項檢查通過，包括疾追者在沒有碰到地圖邊界時能縮短與全速撤退玩家的距離，以及 B Lv.2 和大絕可推開牠。從 APK 抽取的編譯後規則也通過相同重點檢查；簽章與 Manifest 另已驗證。Godot 視窗中以人工場景檢查設定頁及敵人外觀，並非完整真人遊玩。

[固定控制器對照](short-run-probe-v0.16.txt)：不使用大絕的 A、B、C 三條固定路徑均在終段失敗；設定血量不高於 60 時自動施放大絕，A 與 B 路徑完成、C 路徑在終段失敗。這是固定瞄準最近敵人及固定 B 蓄勢節奏的單一控制策略，不能代表真人勝率，也不能拆分大絕的傷害、推開和保護效果。難度可能偏高；是否有趣或公平由實玩判斷。

v0.15 APK 保留且雜湊未變。前版自動探針以現行原始碼重跑時會使用現行場次排程，歷史輸出僅供參考。
