# 奈奈 v0.17：局內成長與守關試玩

更新：2026-11-18。**Status:** implemented · Android debug APK 已建置，尚待使用者實玩與回饋。

這版要觀察：打怪和拾取是否讓你期待升級？強化後是否想立即試招？整局結束時，會不會想到下一局想怎麼玩？

## 如何開始

1. 安裝 [Android 安裝說明](android-install.md) 所列 v0.17 APK，開啟後選「森林短局 · 四段冒險」。
2. 選 A 穿影爪、B 游走蓄勢或 C 獵痕重咬開局。擊殺敵人後靠近掉落的經驗；升級時選一項強化。
3. 最多裝兩個核心，其中一個可升至三級。升級選單的「查看核心後續」可查看發展方向。選完後左右手都重新觸碰，才會繼續移動及攻擊。
4. 三段結束後自動回收本段遺留經驗、恢復最多 25 生命並預告下一段。末段擊敗守關者即勝利；守關者血量下降到刻度時會預告支援。
5. 建議至少各用 A、B 起手遊玩一次。若中途失敗正常結算即可，重點是記得哪些強化有感、何處想繼續或停止；C 可視興趣再試。

## 能力變化

- A：連續命中讓爪影變強；二級以上受到實際傷害會清空連擊，三級滿連擊時爪影變寬。
- B：放開攻擊並移動以蓄勢；二級推開非獵痕敵人，三級最多存兩次蓄勢。
- C：重咬標記並追擊，下一次重咬兌現；二級兌現波及附近敵人，三級兌現後存活的獵物保留獵痕。
- 共通選項包含攻擊傷害、攻擊距離與生命；這些和核心進階都會消耗升級機會。

## 測試與限制

開發檢查：既有規則 176、構築實驗 55、跨段 44、成長規則 31、實際場景流程 39，共 345 項通過；APK 簽章、Manifest 與封裝後的成長與跨段規則另已檢查。這些不能證明手機觸控、效能、平衡、爽感或重玩意願。

[固定控制器紀錄](short-run-probe-v0.17.txt) 使用 30 Hz 最近敵人策略、固定候選種子及低血量自動大絕。無測試無敵的 A／B／C 開局各一輪都到達 Lv.7，但均在終段失敗；加入測試專用無敵後三輪完成。額外受保護的 A＋B、B＋A 亦可完成。自動操作不代表真人勝率，也不能證明終戰難度公平；若你的實玩遇到突發無退路或不想繼續，請以你的體感為準。

完整規格及邊界見 [成長短局規格](../design/nana-growth-run-proposal-v0.17.md)。APK 與簽章詳見 [建置收據](../../tools/android-build.json)；尚未取得本版實機安裝與遊玩證據。
