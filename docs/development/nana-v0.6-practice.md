# 奈奈 v0.6 戰鬥練習

本版提供固定能力的奈奈與四種普通敵人。選單可進入三分鐘自由練習，或選擇追逐者、衝撞者、投擲者、守衛者、混合敵人五個短情境。短情境的目標是在三分鐘內擊敗所有敵人；生命歸零或時間到仍有敵人時失敗。

左手移動，右手拖曳瞄準攻擊。成功爪擊三次後準備重咬；有合法目標時，下次爪擊仍傷害範圍內敵人，再對鎖定目標追加一次可能落空的咬擊。大絕以右側按鈕主動釋放，開場可用，冷卻 40 秒。

敵人的生命、傷害及動作數值是測試起點。衝撞者直線衝刺，投擲者發射直線彈體，守衛者揮擊扇形；觀察預警，避開後利用收招接近。重咬可以中斷衝撞者及投擲者的預警，也可以延長守衛者的收招。

請依序試玩單一敵人，再進入混合情境。主要回饋：近戰與重咬是否順手、敵人的預警及反擊時機是否看得懂、大絕在救場或進攻時是否有感。也請留意按鍵遮擋、卡頓和你使用的手機型號。

規則及場景自動檢查共 173 項通過；Mac 原生畫面已檢查選單、混合情境的預警及大絕按鈕。APK 簽章、Manifest 與封裝規則已檢查，**尚未在 Android 實機安裝或試玩**。自動模擬無法證明手感、平衡與設備相容性。

短情境是固定敵群，並非完整一局。成長、精英、Boss、動態出怪、完整出生預警與普通敵人分離尚未實作；現有完整一局草案見[戰鬥設計](../design/nana-combat-design-v1.md)。
