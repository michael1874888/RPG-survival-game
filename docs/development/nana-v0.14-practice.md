# 奈奈 v0.14：森林短局

更新：2026-11-16。**Status:** implemented · 已收到實玩回饋，核心樂趣與重玩目標尚未成立。

2026-11-16 實玩更新：使用者以 A、B 開局，均打到最後一段（是否完成未確認）。回饋為單調、機制不夠豐富、打怪輕鬆且未使用大絕，缺乏再玩吸引力；詳見 [回饋紀錄](../design/poc-feedback-and-followups.md#v014-完整短局回饋2026-11-16)。本頁下方規則及開發證據保留，不能視為樂趣驗收通過。

從主畫面選「森林短局 · 四段冒險」，選 A／B／C 的一種開局。四段依序是開路、混合威脅、厚血追兵及精英終戰。每段清完才能繼續，段間選擇發展、加裝或替換能力，恢復 25 生命並保留生命與大絕冷卻；最多兩個能力、最高 Lv.2。最後擊敗精英並清完敵人即完成，死亡或該段逾時則結束。

第三段追逐者生命 32，未加成的 B 蓄勢爪為 22 傷害，讓 B Lv.2 推開仍存活的敵人有機會發揮。第四段追逐者生命 26，精英沿用現有行為。每段最後一批在 45 秒安排，清完可能再多花一些時間；前 3 段上限各 75 秒，終段 90 秒。這些數值是試玩起點，3–5 分鐘是目標，不保證所有成功局都在此範圍。

建議正常玩一輪，觀察整局有沒有成長、喘息、壓力及結尾；也可從 B 開局，第一段後選 B Lv.2，看第三段推開敵人後是否能創造前進或反擊機會。留意何時想用大絕、是否想再玩一次，以及哪個選擇讓打法不同。原三連戰與單場比較仍可由主畫面進入。

306 項規則及場景檢查通過；[三種開局的固定控制器紀錄](short-run-probe-v0.14.txt)在生命不高於 60 時自動放大絕，分別完成約 198–205 秒。這些控制器無法代表真人操作、趣味、平衡或手機效能。本版已收到上述實玩回饋，具體設備、安裝方式及效能量測未提供。
