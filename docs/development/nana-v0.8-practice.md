# 奈奈 v0.8 專精比較

這版重做兩個主專精，讓選擇立即改變普通攻擊。遊戲與數值仍是試玩起點，平衡待真人確認。

進入角色選單的「專精快速比較」，先選基礎連抓、掃群・環掃或狩獵・點殺，再選追逐者群、投擲者混合、守衛者或精英守衛。相同敵群的初始位置、敵人數量與能力固定；三分鐘內清除可完成情境。結束後可選「更換打法或敵群」，重選另一種打法比較。

- **掃群・環掃：** 普通爪擊覆蓋較寬，每第三次出手攻擊奈奈周圍一圈，空揮也會推進次數；畫面提示下一次環掃。
- **狩獵・點殺：** 每次爪擊只命中瞄準範圍中的一隻敵人，距離較長；重咬會留下短暫破綻。獵物和破綻有不同的圈形提示。
- 兩路仍使用原本的移動、瞄準與大絕操作。選「成長挑戰」則可在第四級起從升級選項選取新專精，繼續體驗普通強化與精英。

建議先用同一組敵人分別玩掃群、狩獵，觀察選完後前幾次攻擊、面對包圍與接近強敵的差異。重點回饋是兩路是否改變你的站位與目標選擇、哪裡感到不公平，以及範圍提示與破綻是否看得懂。

開發端驗證了命中數量、環掃循環、目標死亡後的重咬保留、一般升級與影化下的限制、選單切換與重玩。Mac 原生畫面檢查了比較選單與狩獵提示；自動模擬無法證明平衡。Android APK 尚未由開發端在手機安裝或試玩，檔案和安裝方式見 [Android 安裝說明](android-install.md)。

進階子分支仍保留在 [專精重整規劃](../design/nana-specialization-rework-plan.md)，待主專精試玩後再決定。
