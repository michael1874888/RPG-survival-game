# 奈奈 v0.15：森林短局戰鬥決策

更新：2026-11-16。**Status:** implemented · 已收到實玩回饋，戰鬥決策目標尚未成立。

實玩更新：使用者回報仍簡單、缺少追擊及腹背受敵感、敵人一兩下被清除，未使用大絕。本版戰鬥決策目標尚未成立；詳見 [回饋紀錄](../design/poc-feedback-and-followups.md#v015-追加回饋2026-11-16)。下方為當時實作與開發驗證，不代表真人驗收。

上一輪回饋是操作順，但敵人太好處理，缺少需要判斷的時刻；因此本版維持四段短局及能力規則，調整敵人出場、組合與視覺提示。目標是觀察走位、優先目標、進退和大絕是否有值得選擇的時機。

主畫面選「森林短局 · 四段冒險」，選 A 或 B 開局，段間依自己的想法發展、加裝或替換。三段後各恢復 25 生命，上限 100，保留已有能力進度及大絕冷卻；死亡或逾時結束整局。

- 第一段：追兵包圍中加入衝撞者，留意預警線與衝刺後的反擊。
- 第二段：追兵與投擲者、衝撞者交替出現，留意是否想先處理遠程威脅。
- 第三段：32 血追兵、投擲者與守衛；B Lv.2 可以推開存活的非獵痕目標。
- 第四段：精英在 10 秒排入，與追兵、投擲者混合；仍需清完排程和敵人才通關。

追兵最後一批於每段 36 秒排入，前 3 段各有 75 秒上限，終段 90 秒。特殊敵人原有攻擊預警、安全出生與併發限制保留。衝撞者、守衛與精英的收招階段加上藍色圓環及「空檔」提示，標示其暫不攻擊的時間，並不保證接近時不會受到其他敵人傷害。

**試玩一輪即可：**先自由選 A 或 B，注意自己有沒有為了躲招、突破包圍或處理投擲者而改變行動；留意「空檔」是否看得懂、大絕何時想用，以及失敗時原因是否明確。如果打到較晚階段覺得過難，記下在哪一段與當時情況即可，不需要反覆重試。

[固定控制器對照](short-run-probe-v0.15.txt)分別試三種開局、不使用大絕及血量不高於 60 時自動施放：前者 1／3 通關，後者 2／3 通關，其中 B 開局兩種策略均在終段失敗。這是同一套簡化控制器及固定升級路徑的觀察；B 的時機未依實際威脅調整，不能代表真人勝率，也無法證明大絕的單一效果或遊戲已經有趣。需實玩確認難度是否過高、不同戰況是否清楚，以及哪個選擇有感。

開發端 307 項規則與場景檢查通過；APK 的簽章、封裝與抽取後四段關鍵規則通過。以人工狀態查看段間、結算及守衛收招提示；不是完整真人遊玩。Android 裝置安裝、觸控、效能與主觀體驗仍待驗證。原 v0.14 APK 保留，原三連戰與單場入口仍可使用；v0.14 探針依賴當時的場次排程，現行程式已更新，歷史輸出保留作參照。
