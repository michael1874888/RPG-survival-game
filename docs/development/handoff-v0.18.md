# 奈奈 v0.18 交接

更新於 2026-11-18。專案根目錄為 `/Users/junming/Codex_ws/RPG_Game_Dev`。本文件記錄 v0.18 的目標、修改與驗證狀態。

## 修改背景與目標

v0.17 首輪真人回饋顯示，A 換成 B 會改變打法，能力在守關時有用途，紅色疾追者追擊最有壓力，中途想停止的感覺減少，但持續重玩的吸引力普通。玩家提出寶物收藏與跨局強化可能是重玩誘因。

v0.18 的實驗聚焦「同樣使用 B 開局，兩種三級分支是否讓玩家想嘗試另一局，以及如何應對疾追者」。寶物收藏作為後續候選，需結合試玩結果討論。玩家覺得回身追咬打最後守關者較輕鬆，雙發蓄勢在一般戰況較輕鬆。願意試不同路線，玩完後再開一局的意願仍不強。

## 修改內容

森林短局升級時，選到 B 游走蓄勢 Lv.3，進入二選一畫面，消耗同一次升級：

- **雙發蓄勢**：最多儲存兩次蓄勢爪，沿用 v0.17 的 B3 效果。
- **回身追咬**：最多儲存一次。蓄勢爪推開仍存活的目標後，取最接近瞄準方向的被推目標，顯示金色記號兩秒。下一次爪擊命中該目標時追加一次傷害；下一爪未命中、目標死亡、記號逾時或換段時清除。傷害基礎為 10，會依現行傷害倍率及共通成長結算。
- C 獵痕與追咬記號分開處理。既有 B2 不推開 C 獵痕目標的例外仍適用。重試重置分支，跨段保留本局所選分支。

選卡說明、畫面記號、B 狀態及結算顯示同步更新。現行效果以程式為準，[提案](../design/nana-b-branch-playtest-v0.18.md)與[試玩說明](nana-v0.18-practice.md)提供設計和操作背景。
