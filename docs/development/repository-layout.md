# Repository 整理範圍

本 repository 用於保存原創遊戲開發與調查脈絡，初次整理版本為 PoC v0.4。

## 納入版本管理

- `game/`：Godot 場景、原始碼、測試、資產匯入描述、中文字型及字型授權。
- `docs/design/`：主題與角色、五輪共識、原型規格、各輪問題與回饋、分階段路線。
- `docs/research/`：同業機制調查、來源筆記、特定版本的靜態分析與雜湊清單。
- `docs/development/`：開發環境說明、測試方法、歷史檢查與建置紀錄。
- `scripts/`、`tools/research/`：遊戲測試、建置及研究輔助程式。
- `tools/*.json`：工具與最新 APK 的來源／雜湊收據；本機編輯器設定備份除外。
- 根目錄文件與啟動入口，以及可供新環境設定的 Android preset 範例。

## 不納入版本管理

- Godot 匯入快取、編輯器狀態與實際匯出 preset。
- 私鑰、keystore、憑證容器、環境密碼檔及本機設定備份。
- APK／AAB、競品 APK／XAPK、擷取資產、SDK／JDK／Godot 安裝包與其他大型產物。
- 本機 `.agents/` skill 安裝；它是分析工具的依賴環境，並非原創遊戲原始碼。

以上由 `.gitignore` 管理。競品原始包與大量產物留在原開發 SSD，各報告保留檔名、版本與雜湊供對照。

## 路徑、歷史與授權

報告及收據中的 `/Users/...`、`/Volumes/...` 是原開發環境的歷史路徑，不是雲端附件，也不表示新環境必須使用同一個使用者名稱或 SSD 掛載名稱。保留這些位置是為了追查既有證據；一般啟動以相對路徑的 `game/project.godot` 為準。

repository 的可玩程式為本專案原型；競品研究結果不等於取得競品素材或程式的使用授權。Noto Sans TC 遵循隨附的 SIL OFL。原創專案的正式授權與發行條件尚未決定，本次不自行加上開源授權。
