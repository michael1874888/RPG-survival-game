# 奈奈 v0.13：壓力與構築發展試玩

更新：2026-11-15。**Status:** implemented · 開發驗證完成，尚待本版 Android 試玩。依 v0.12 的試玩回饋，先校準遭遇，再單獨對照 C／B＋C，最後加入段間發展；隨機構築仍未加入。[安裝與 APK](android-install.md)

## 這次想觀察什麼

1. 敵人靠近、混合攻擊或支援累積時，走位與大絕是否有清楚用途？
2. B＋C 的「留痕 → 遊走蓄勢 → 打中獵痕 → 下一擊重咬」是否能理解與實際完成？
3. 下一段來臨時，發展原能力、加裝能力與替換能力，是否各有值得選擇的理由？

主畫面選「三連戰 · 段間構築」，開局選 A／B／C 其中之一。每段勝利後選一次：**發展**一個既有能力至 Lv.2、**加裝**另一個 Lv.1，或在兩格已滿時**替換**其中一個為新的 Lv.1。Lv.2 為本輪起點，最高 Lv.2；替換會失去舊能力、等級及其進度，而且這次不能同時升級。若前段已將唯一能力升到 Lv.2，下一段只能加裝另一個。

## 本版規則

- 三段維持清路、混合威脅、強敵帶支援；每段最多 60 秒。E1 增加追逐者並加密來襲，E2 提早安排混合威脅，E3 的精英支援由每 6 秒縮短至每 4 秒。E2 沒有新增守衛阻擋攻擊的規則。位置、預警、安全重試與玩家移動仍影響實際接敵；不是完全相同的錄製重播。
- C 獵痕不再倒數，直到目標死亡、兌現，或重咬其他目標而轉移；沒有跨段保留。標記目標只有在合法重咬範圍／角度內才會優先選到，重咬前搖仍可能揮空。
- B＋C 的蓄勢爪擊若命中仍存活的獵痕目標，且同一次出手沒有已經觸發重咬，會把重咬蓄至 3 格；下一次出手仍須有合法目標才能咬。命中擊殺獵物或該次已觸發重咬不會額外補滿，不會遞迴。
- 開局各能力 Lv.1，維持其核心操作：A 每三次命中發動長條爪影；B 停手移動蓄勢、命中才消耗；C 重咬留痕並再次咬中兌現。
- **A Lv.2：**每次爪影也朝觸發方向的反面延伸，前後各長 340、寬 90；同一敵人每次爪影最多受一次 8 傷害。
- **B Lv.2：**蓄勢爪命中後，存活的非獵痕目標被向外推 65 遊戲單位；追逐者原有普通擊退仍適用。獵痕目標不被這個額外效果推離，不改特殊攻擊狀態。
- **C Lv.2：**兌現重咬時，以被咬目標為中心對附近其他活敵造成 8 傷害，範圍 110 加敵人半徑；不重複傷害主目標、不蓄咬、不遞迴觸發能力。
- 段間恢復 25 生命，上限 100；生命、大絕冷卻、剩餘大絕增幅與保留能力的可保存進度沿用 v0.12。選擇時凍結戰鬥時間。死亡或逾時結束整輪，重試從第一段開始。兩個段間選擇各消耗一次機會，數值及 Lv.2 設計均待試玩。
- 大絕沿用 v0.12 的範圍傷害、短暫保護、追逐者推開及增幅，仍為 40 秒冷卻；本版沒有改成命中充能。

## 建議怎麼玩

先正常玩一輪，按自己的判斷使用能力及大絕。第一段後選發展或加裝；下一次再考慮發展或替換。若想對照 B＋C，可開局選 B、第一段後加裝 C，再找強敵：先咬出粉紅獵痕，停手移動蓄勢，再用蓄勢爪打中獵物並繼續瞄準重咬。藍色提示是當前預計重咬目標，粉色是獵痕。

想請你留意：哪一刻想用大絕、是否理解選擇帶來的變化、B＋C 是否自然，以及受傷是否讓下一段需要改變策略。原本「選擇能力與情境」入口保留單場實驗；單場使用 Lv.1 能力，方便比較。

## 開發證據與界線

- [286 項規則與場景檢查](test-results-v0.13.txt)，包含永久獵痕、B＋C 命中／已重咬／擊殺、三種 Lv.2、段間選項與跨段狀態；APK 另驗證編譯後的關鍵規則。
- [能力修改前的遭遇探針](pressure-v0.13-before-abilities.txt)：E1 固定站樁、固定方向攻擊的基礎配置失敗；會走位並瞄準最近敵人的基礎配置滿血完成。E3 在這兩種控制方式下呈現不同結果。控制器不是玩家，不應由單一結果推斷難度。已用現行 [探針](../../scripts/research/probe-nana-pressure-v013.gd) 加 `NANA_LEGACY_C=1` 重跑，站樁及走位各 21 筆摘要均與修改能力前完全一致。
- [C／B＋C 遭遇對照](c-comparison-v0.13.txt)在相同控制器下，新舊 B＋C 的 E3 輸出相同，這個控制器未可靠製造新互動。另以 [固定目標探針](bc-fixed-target-v0.13.txt)分別切換持續獵痕與蓄勢回報；後者直接設置滿蓄勢、目標靜止、沒有敵方反擊，只證明條件下的規則差異，不代表真人會觸發或覺得有趣。
- [三連戰探針](series-probe-v0.13.txt)遍歷 30 條合法選擇路徑：最近敵人控制器無大絕全部完成，結束生命介於 21–60；另以生命不高於 60 時自動施放的固定策略比較。此觀察顯示本版仍可能不需要大絕，不能宣稱已驗證解圍手感或平衡。單場 E3 基礎控制器未使用大絕時失敗，生命觸發策略則完成；此差異無法單獨拆分傷害、保護與擊退的貢獻。
- Godot 實際場景以人工終局狀態檢查段間選項版面；不是完整真人遊玩。v0.13 尚未在 Android 實機安裝，觸控、效能和趣味待使用者驗證。每段觀察紀錄包含能力等級、選項、選擇及 series_id；儲存失敗會提示，App 被直接終止時不保證完整。

歷史 [v0.12 試玩說明](nana-v0.12-practice.md)保留當時規則；其探針腳本使用舊版三連戰 API，不能直接用 v0.13 原始碼重播。v0.12 APK 保留於 SSD；其簽署及雜湊在本輪匯出前另行核對。
