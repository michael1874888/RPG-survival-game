# 奈奈 v0.11：構築實驗試玩

更新：2026-11-15。v0.11.0 是依 Android 試玩回饋調整的測試版；[安裝與 APK 收據](android-install.md)。

## 這次改了什麼

- **穿影爪 A：**每三次有效爪擊後，從觸發時的位置及方向延遲 0.12 秒打出長 340、寬 90 的長條，碰到的每個敵人受到 8 傷害。長條與敵人圓形碰撞；特效改成三道爪痕與淡色範圍。與 v0.10 的 24° 扇形相比，近處變寬而遠端變窄；這是測試起點，不代表全面強化。
- **重咬選敵與提示：**瞄準範圍內，特殊敵人有相當於 5° 的角度偏好；既有目標要被另一目標超過 3° 才切換。出手前目標死亡或離開範圍即解除。C 的有效獵痕仍在範圍內時優先；瞄向其他方向仍可換敵。重咬出手後，提示維持在已鎖定的目標，目標死亡則取消提示；前搖後仍有可能因移動而揮空。青色弧線與箭頭顯示預計目標，粉紅菱形／圓環代表 C 獵痕。
- **E3 強敵帶支援：**維持原本同一隻精英及支援事件表，精英生命由 260 調為 320，增加追擊機會；其他情境敵人不受影響。B 的能力規則保留。

## 怎麼比較

1. E1 清路：先不裝能力，再單裝 A。留意能否看到爪影、是否需要轉向排線，以及有沒有打到普通爪擊範圍外的敵人。
2. E3 強敵帶支援：先不裝能力，再單裝 C。觀察青色提示是否在你想咬的敵人上、手指微動時是否穩定、能否看懂粉紅獵痕及再次咬中。目標離開攻擊範圍仍可能咬空。
3. 若想比較 B，可在相同情境試一場，留意停手移動換爆發是有節奏還是感到疲累；不要求一次跑完。

## 開發驗證與界線

176 項既有規則、43 項構築規則、16 項真實場景流程檢查通過。Android APK 已做獨立簽章、架構、Manifest 和從封裝提取的規則檢查；使用者隨後回饋「現在有符合預期，可以繼續」；此次未新增裝置資訊及逐項操作紀錄。新一輪已進入 [v0.12 三連戰](nana-v0.12-practice.md)。

[固定控制器結果](build-experiment-probe-v0.11.txt)：E1 單 A 11 次爪影合計命中 7 次；E3 基礎配置完成、單 C 留痕 3 次並兌現 3 次，單 B 在固定輸入下失敗。控制器未使用大絕，不代表真人勝率或平衡通過；E3 比 v0.10 更耐打，需要注意 B 與基礎配置實際體感。
