# 奈奈 v0.19：回身鈴鐺試玩

2026-11-19。使用者已確認實作 [鈴鐺設計](../design/nana-treasure-proposal-v0.19.md)。Android 測試版已匯出；手機安裝、畫面、保存與試玩感受待實測。

1. 選「森林短局 · 四段冒險」。可以任選起手，完成第三段後取得回身鈴鐺；守關失敗也會保留。尚未取得前便結束，則不會取得。
2. 結算後自行決定要不要再開局。準備頁可裝卸鈴鐺，選 B 起手才會在該局生效；第一次取得不會自動裝備。
3. 裝備時，把 B 升到二級即可推開並回身追咬。本局固定追咬，最多存一發，A、B、C 都不再提供三級核心；共通強化則可到三級。不裝鈴鐺時沿用 v0.18 的 B 三級兩條分支。
4. 試用後自由決定繼續或停止，記下升級順序、何時用到追咬，以及是否還想試其他寶物。

收藏存在裝置的遊戲資料中；解除安裝並清除資料可能移除收藏。記錄取得、裝卸及開局的本機觀察資料僅供實驗分析。若畫面顯示未能保存，可在段間重試。

自動規則、存檔及實際場景流程檢查通過；包含橫向基準畫面的面板範圍檢查，不能代替手機瀏海、文字可讀性或觸控實測。APK 的簽章、版本、架構及封裝後鈴鐺規則已驗證。數值與重玩意願須以真人體感判斷；一件寶物無法證明玩家會真的去找下一件。
