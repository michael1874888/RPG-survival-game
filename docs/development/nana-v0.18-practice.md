# 奈奈 v0.18：游走蓄勢分支試玩

2026-11-18。Android ARM64 debug 版已建置與驗簽，已收到真人分支比較回饋；設備型號及安裝方式未提供。手機選「森林短局 · 四段冒險」，用 B 游走蓄勢開局。把 B 升到三級時，可在雙發蓄勢與回身追咬中選一條。

- 雙發蓄勢可儲存兩次蓄勢爪。
- 回身追咬最多儲存一次。蓄勢爪推開仍存活的敵人後，金色記號顯示兩秒。下一次爪擊命中目標，會追加一次傷害。該次爪擊未命中目標，記號消失。
- 若敵人是 C 的獵痕目標，既有 B 二級不推開該目標的規則仍有效。回身追咬使用獨立記號。

試玩時留意紅怪追上來後，你是否想退開、追擊或接連清路。結束後觀察自己是否想用另一條分支再玩一次。選卡與效果的可讀性也需要在手機上確認。

完整自動測試共 356 項通過，包含場景、紀錄寫入、跨段和分支規則；封裝後的 B 分支規則也通過檢查。相同種子固定控制器選 B+C，雙發與追咬均於守關失敗，分別 10.1 與 16.7 秒；兩者第三段入場與生命狀態不同。這是受控程式操作的觀察，不能推論真人難度、平衡或樂趣。
