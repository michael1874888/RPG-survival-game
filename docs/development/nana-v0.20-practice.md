# 奈奈 v0.20：首章完整循環試玩

2026-11-20。使用者確認完整設計後，要求開始實作；本版為 D1 的 **R1 首章試玩**，不是三章完整首發，也不是商店發布候選。完整方向見 [主設計](../design/nana-full-version-design-v1.md)、[內容表](../design/nana-full-version-content-v1.md)、[製作與發布門檻](../design/nana-full-version-release-plan-v1.md)。

## 怎麼開始

1. 開啟 Android 測試包後，選「準備出發 · 月下庭院」。選穿影爪、游走蓄勢或獵痕重咬起手；已收藏的習慣寶物與隨身小物各可選一件，也可空裝。起手不符合的習慣寶物會提示本局不生效。
2. 左手移動、右手拖曳瞄準並持續攻擊；點「夜影解放」使用大絕。移動、抓擊、咬擊、蓄勢與選敵延續先前操作；升級時選一張卡，必要時可刷新或略過。
3. 一局有九場戰鬥，第三、六場是精英，完成後可開收藏箱、在營地選一條路；第九場是守關者。營地兩種路線各有不同風險，選取前會顯示條件與獎勵。
4. 新收藏立即保存供下一局使用。尚未收藏回身鈴鐺時，第一次完成第三戰會先取得它；舊版已有鈴鐺者不重複給。準備畫面可設定其他尚未取得的尋寶目標，普通收藏箱會優先納入目標；首次保證鈴鐺優先。
5. 結算後自行決定是否換裝再出發。也可在首頁進入六種成形的練習；練習不改變冒險與收藏。準備頁可開啟降低敵方傷害的輔助。

A、B、C 各有兩條成形分支；普通升級在第一精英後開放一條三級成形。對應的習慣寶物讓該核心升到二級時提早成形，並預留本局的成形名額。每局最多兩種核心、一種成形；還有六張流派修飾、三張跨核心聯動與六種共通強化。營地兩次合計可花一次刷新調整一張非核心天賦。

戰鬥可暫停並選「保存並回到起點」，之後從首頁繼續；切背景也會暫停並嘗試保存。戰鬥定期保存，選卡、選路、領收藏及結算亦會保存。儲存失敗會提示重試。收藏存在裝置的應用資料中，移除應用及其資料可能連收藏一起移除。

## 試玩時留意

不用按指定路線測試，也不必為了完成比較而強迫自己再玩。若方便，記住：

- 有沒有哪場戰鬥讓你因敵人的招式改變站位、目標或使用大絕？哪一段最想停？
- 哪一次升級或營地選擇真的值得思考？兩種成形的打法差在哪裡？
- 取得寶物後是否自然想裝備再開局？試用完後，自己是否還想找下一件或試另一套打法？
- 戰鬥是否太短、太簡單、太亂或等待過多？手機型號、Android 版本、是否由舊版更新及任何存檔／觸控問題也有助重現。

## 本版已做與尚未完成

本版包含首章五種普通敵、兩種精英與一位守關者，兩次營地從六種事件中選路，六件首章寶物、兩格裝備、尋寶目標、標準／輔助、練習、結果、收藏與續玩。場景沿用同一個基本開闊庭院；EV03 提供敵種和守關招式**文字預覽**，尚無完整動畫示範。簡潔的畫面及合成音效供本階段觀察規則使用。

R2 仍需完成第二／三章、其餘敵人與 Boss、完整 24 天賦、12 寶物、多場地、三級難度、成就與其餘首發功能；R3 需完成裝置、效能、發布包、授權與商店資料。此版本不能宣稱達到 App Store 上架標準。

## 開發驗證與證據界線

- `bash scripts/test-game.sh`：舊版回歸 377 項；R1 受控九戰／獎勵流程 71 項、規則與 80 組成長路徑 4,088 項、實際場景流程 27 項，合計 4,563 項通過。自動無敵只用於部分流程測試，不在遊戲中。
- 六成形、R1 天賦互動、六事件與限時成功／失敗、成長容量、經驗預算、同幀傷害、守關者、舊鈴鐺遷移、受損主存檔由有效備份恢復、快照與亂數續接均有受控案例；測試副本不使用玩家的收藏檔。
- 電腦上的獨立資料畫面已檢查首頁、準備、戰鬥、暫停／續玩、營地、威脅預覽及天賦調整；這不代表各種手機螢幕、瀏海及多指操作已通過。
- 電腦測試在場景釋放後立刻結束程序，仍曾出現一個 `AudioStreamGeneratorPlayback` 結束時未釋放的警告；已加入音訊離場清理，等待 0.5 秒再結束的獨立測試未重現。這不足以證明手機長時間運行沒有資源問題，留待裝置與效能驗收。
- [自動操控探針](../../game/tests/r1_autoplay_probe.gd) 以同一種子、無無敵、即時朝最近敵人瞄準、固定選安全路線並跳過箱子等獎勵，三個起手均到達終局，戰鬥時間分別為 152.0、164.6、148.1 秒。此結果低於 8–10 分鐘的設計假設，是節奏風險；它跳過真人反應及選單時間，**不是玩家局長、真人勝率或樂趣證據**。重現：`Godot --headless --path game --script res://tests/r1_autoplay_probe.gd`。
- Android 包已獨立驗證 ZIP、ARM64、v2／v3 簽章、Manifest、啟動場景資源、授權檔與包內編譯後 R1 規則；套件 ID 與簽章指紋和 v0.19 相同。當前沒有連線的 Android 裝置，尚未實機安裝、更新、遷移或測效能。
- 這台 Mac 目前選用的是 Command Line Tools，`xcodebuild` 回報需要完整 Xcode；R1 計畫中的早期 iOS 匯出／安全區／觸控檢查因此尚未完成。iPhone 交付需要後續可用工具鏈與裝置，不能由 APK 代替。

最新檔案位置、大小、雜湊及檢查結果見 [Android 建置收據](../../tools/android-build.json)；安裝方式見 [Android 安裝說明](android-install.md)。v0.20 原始碼整理於 `feature/nana-v0.20-r1`，v0.19 包與既有提交仍保留。
