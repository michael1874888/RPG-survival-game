# 主題與角色方向

## 已確認

- 核心是手機生存動作遊戲，追求構築選擇與清怪爽感；技能來源不限定法師或魔法。
- 融合可愛動物，每隻動物的專屬基礎攻擊與本身特色有關，另搭配部分共通升級。
- 能力可作童話式誇張，也可延伸魔法或道具，但仍應能聯想到動物特色。
- 奈奈的抓、咬是攻擊設計素材，能力形式可延伸；角色需要可主動釋放、有冷卻時間的大絕招，具體方案由 Codex 評估後提出。
- 可愛角色、誇張戰鬥、非血腥退場。
- 正式 UI、美術、主題與可能的故事呈現需要後續完整規劃。
- 第一版先聚焦家中的黑貓「奈奈」，完成其攻擊與機制，再完成敵人設計；其他角色保留擴充空間。細節見 [第一版戰鬥設計計畫](first-version-combat-plan.md)。

## 原型角色與未來候選

| 動物 | 目前狀態 | 特徵與設計依據 |
| --- | --- | --- |
| 刺蝟 | 已實作的首個原型角色 | 方向性尖刺；散射與反彈已有正向清怪回饋；穿透近期暫緩深化 |
| 小熊 | 已實作的比較角色 | 近距離熊掌揮擊；使用者認為操作要求較高，但較高基礎攻擊力讓體感仍可接受 |
| 奈奈（黑貓） | 使用者已選定的第一版主角，原型為家中寵物黑貓 | 抓、咬與主動大絕已做成戰鬥練習；升級仍為設計提案，手感待驗證 |
| 約克夏 | 使用者希望未來加入家中寵物 | 汪汪叫、咬人、高興時繞著人轉圈圈；不把所有行為直接定為攻擊技能 |

第一版聚焦奈奈；刺蝟、小熊為既有原型，約克夏為未來候選。其他角色的加入順序與正式首發名單仍待後續決定。

目前已提出 [奈奈戰鬥設計草案 v1.1](nana-combat-design-v1.md)，比較近戰、爪影與法術型攻擊後，推薦連抓、自動重咬與主動大絕「夜影解放」。這組能力已製成 [v0.5 手感試玩](../development/nana-v0.5-practice.md)；影化與爪影尚未確定世界觀或正式名稱。

## 尚未決定

正式遊戲名稱、世界觀、動物的關係與動機、敵人身分、故事主線與篇幅、美術風格、正式場景與介面視覺均未定案。Bramble、森林、守護森林等現有名稱與文案是測試用表現，不代表已確認故事設定。

後續主題研究應釐清玩家要保護、探索或達成什麼，動物與敵人為何交戰，以及故事如何出現在短局流程中；再據此設計視覺與音效。
