# 主題與角色方向

## 已確認

- 核心是手機生存動作遊戲，追求構築選擇與清怪爽感；技能來源不限定法師或魔法。
- 融合可愛動物，每隻動物的專屬基礎攻擊與本身特色有關，另搭配部分共通升級。
- 能力可作童話式誇張，也可延伸魔法或道具，但仍應能聯想到動物特色。
- 可愛角色、誇張戰鬥、非血腥退場。
- 正式 UI、美術、主題與可能的故事呈現需要後續完整規劃。

## 原型角色與未來候選

| 動物 | 目前狀態 | 特徵與設計依據 |
| --- | --- | --- |
| 刺蝟 | 已實作的首個原型角色 | 方向性尖刺；散射與反彈已有正向清怪回饋；穿透近期暫緩深化 |
| 小熊 | 已實作的比較角色 | 近距離熊掌揮擊；使用者認為操作要求較高，但較高基礎攻擊力讓體感仍可接受 |
| 黑貓 | 使用者希望未來加入家中寵物 | 抓人、咬人；技能、升級與加入時點未定 |
| 約克夏 | 使用者希望未來加入家中寵物 | 汪汪叫、咬人、高興時繞著人轉圈圈；不把所有行為直接定為攻擊技能 |

上述原型角色不等於正式首發角色名單；寵物候選仍需設計不同用途與打法。

## 尚未決定

正式遊戲名稱、世界觀、動物的關係與動機、敵人身分、故事主線與篇幅、美術風格、正式場景與介面視覺均未定案。Bramble、森林、守護森林等現有名稱與文案是測試用表現，不代表已確認故事設定。

後續主題研究應釐清玩家要保護、探索或達成什麼，動物與敵人為何交戰，以及故事如何出現在短局流程中；再據此設計視覺與音效。
