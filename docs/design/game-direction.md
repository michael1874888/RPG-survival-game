# 遊戲方向草案

更新日期：2026-11-14。階段：核心玩法原型已開始。本文保留逐輪決策與待決問題，實作範圍見原型規格。

## 最新交接與待決方向

v0.9 已交付分批怪潮及狩獵快攻／重擊比較。使用者回報成長後期尚可、同密度單點較吃力後，要求重新盤點設計並研究同類遊戲；結果見 [設計盤點](nana-v0.9-design-audit-2026-11-14.md)。隨後提出 Balatro 式「依隨機機會形成攻擊打法」的想法，並要求評估成長模式或新模式；[研究結果](../research/random-driven-combat-mode-feasibility-2026-11-14.md)推薦先評估分段構築實驗，仍待使用者 review，未實作。新 session 先讀 [HANDOFF.md](../../HANDOFF.md)。

## 最新開發順序：先完成一個角色與敵人

使用者已調整第一版方向：先聚焦一個角色，完整設計攻擊模式與機制；再設計第一版敵人的種類、特色、攻擊模式與機制，之後處理其他部分。第一版主角已選定為家中的黑貓「奈奈」，以抓、咬作為特色依據；具體能力待設計。保留其他角色的擴充空間，其他角色安排在核心完成後。

目前依 [單一角色與敵人戰鬥設計計畫](first-version-combat-plan.md) 推進。下方五輪共識與 PoC 是既有依據；後續新增角色比較及零散能力實驗的順序，以本次調整為準。

使用者指定由 Codex 先規劃，自己負責 review 或開發方向決策。[奈奈戰鬥設計草案 v1.1](nana-combat-design-v1.md) 已提出近戰連抓、自動重咬、敵人與完整戰鬥的推薦方案；使用者同意後，已先交付 [v0.5 奈奈手感練習](../development/nana-v0.5-practice.md)，角色及敵人細節仍需試玩收斂。

最新 review 要求：奈奈需要可主動釋放、有冷卻的大絕招；抓、咬是特色來源，可延伸其他能力，現有方案可在評估後保留。v0.5 以「夜影解放」短暫影化、6 秒持續與 40 秒冷卻作為已獲同意的試玩起點；名稱、效果與數值可依手感調整。

## 使用者已確認的方向

| 面向 | 已表達的方向 | 尚未決定的邊界 |
| --- | --- | --- |
| 平台 | 主要在手機遊玩；iOS、Android 均可，無產品優先偏好；使用者兩種手機都有，第一輪先走 Android | 是否同時首發、最低設備要求與具體實測設備 |
| 操作 | 橫向雙手操作；左側移動，右側拖曳瞄準並持續攻擊，放開停止 | 特殊能力操作、輔助瞄準及實機手感 |
| 戰鬥節奏 | 連續生存；敵人掉落經驗，靠近拾取；升級暫停並三選一；敵群壓力有高低變化 | 經驗曲線、候選池與抽選規則、具體壓力曲線 |
| 單局長度 | 完整一局先以約 10 分鐘為目標；第一個完整短版原型為約 3 分鐘 | 成長速度及實測後的調整、10 分鐘版勝利條件 |
| 核心樂趣 | 法術構築與清怪爽感 | 技能取得、分支、組合、敵群節奏及驗證標準 |
| 角色題材 | 融合可愛動物；不限定法師角色 | 世界觀、視覺風格、角色個性及敵人設定 |
| 角色差異 | 每隻動物有專屬基礎攻擊，再搭配部分共通升級；成長後仍保有攻擊辨識度 | 首批動物、具體攻擊、專屬與共通升級的內容及比例 |
| 能力風格 | 動物特色可以童話式誇張；魔法或道具可作延伸，仍應看得出與動物的關聯 | 世界觀與個別技能的表現 |
| 戰鬥氣氛 | 可愛角色、誇張戰鬥、非血腥退場 | 敵人身分、具體退場方式、美術與音效 |
| 第一版主角 | 寵物黑貓「奈奈」，以抓、咬作為特色依據 | 攻擊模式、能力、升級與生存規則待設計 |
| 歷史首個測試角色 | 刺蝟，朝瞄準方向發射尖刺；散射、穿透、反彈曾作候選升級比較 | 既有原型保留，第一版角色設計改以奈奈為準 |
| 攻擊資源 | 原型基礎攻擊不耗魔、無彈藥限制；奈奈需有可主動釋放、帶冷卻的大絕招 | 大絕效果、操作配置、冷卻長度及後續資源設計 |
| 原型範圍 | 單人離線、一個測試角色、一張小場地；完成戰鬥、局內升級與重新開始 | 具體敵人、升級與勝敗規則；正式版局外養成及連線仍待後續評估 |
| 原型敵人 | 追逐包圍型，以及有明顯預警、朝鎖定方向衝刺的敵人；先完成前者 | 敵人身分、生成配置及速度、傷害等數值 |
| 受傷與失敗 | 採生命值；接觸或攻擊命中扣血；受傷有清楚回饋及短暫無敵；生命歸零結算，可重新開始 | 傷害與無敵時間、回血規則及結算介面 |
| 視角與呈現 | 原型採 2D 俯視角與簡單占位素材 | 正式美術風格、角色造型與鏡頭細節 |
| 短版勝利條件 | 存活約 3 分鐘即成功；成功與失敗均可重新開始 | 計時與結算細節；正式版 Boss 等結束方式仍待後續決定 |
| 協作方式 | 使用者決定方向並提供手機實玩回饋；Codex 整理規格、程式及可執行驗證；小里程碑交付、原型先用免費工具或素材 | 發售時程、額外夥伴或預算均未設定 |

## 目前的設計解讀，待討論確認

「法術構築」可以先視為攻擊效果的選擇、組合與演變；最終技能來源和名稱仍可依動物、道具或世界觀調整。「施法」暫時沿用使用者說法，具體可能對應攻擊或能力施放，兩者關係尚未定義。

歷史首個測試角色是刺蝟；目前第一版主角已改為黑貓奈奈。臭鼬的氣味、兔子的跳躍等仍是後續角色的發想例子，尚未列入原型或正式版名單；所有表現均允許童話式誇張。

## 第一輪：角色特色與構築的關係（已確認）

| 決策 | 已確認的方向 | 要檢驗的取捨 |
| --- | --- | --- |
| 動物特色保留程度 | 專屬基礎攻擊，加上可共享的效果升級；攻擊行為仍保有辨識度 | 角色辨識度、每局自由度與獨立內容的製作量 |
| 能力來源與誇張程度 | 從動物特色出發，再做童話式誇張；魔法或道具可作延伸 | 是否容易聯想到動物、是否容許足夠多的攻擊變化 |
| 整體戰鬥氣氛 | 可愛角色搭配誇張打擊與非血腥退場 | 清怪回饋、世界觀一致性及敵人呈現 |

使用者回覆「都同意」，確認以上三項方向。當輪角色範例僅用於討論；第三輪另行確認刺蝟作為首個測試角色，正式版名單尚未決定。

## 第一個原型需要回答的問題

1. 刺蝟的尖刺是否容易瞄準，擊中與清除敵群是否有清楚回饋？
2. 移動、瞄準與持續攻擊在手機橫向操作時是否舒服？
3. 攻擊升級是否能讓玩家察覺打法改變，而不只看到傷害數字增加？

這些是後續實測問題，尚無測試結論。原型先以短時間片段驗證，再依結果決定是否擴充成約 10 分鐘的完整一局。

## 討論進度

- v0.4 使用者覺得反彈似乎足夠，穿透沒有特別亮眼的地方。近期保留散射＋反彈方向，暫停穿透與陣形的反覆比較，未刪除既有實驗程式；構築多樣性仍待驗證，詳見 [本輪收斂](formation-comparison-poc-v0.4.md)。

- v0.3 使用者回饋散射＋反彈明顯更爽，穿透初期不突出且與反彈部分重疊；已同意接續 [v0.4 陣形比較 PoC](formation-comparison-poc-v0.4.md)，在 45 秒固定構築下比較四面包圍與單向隊列。此輪保留既有攻擊規則，不預設穿透必須勝出。

- 接續 [v0.3 構築比較 PoC](build-comparison-poc-v0.3.md)，先由 Codex 製作刺蝟「廣域清群／集中突破」的快速比較入口與能力回顧，再交付使用者試玩；驗證同一角色的組合是否改變打法。

- v0.2 使用者回饋：小熊近距離攻擊要求較高操作，但較高基礎攻擊力讓體感仍可接受。使用者希望未來加入家中黑貓（抓、咬）與約克夏（吠叫、咬、高興時繞人轉圈）；具體技能與加入順序未定，詳見 [回饋與未來角色候選](poc-feedback-and-followups.md)。

- 使用者要求繼續後，開發端以小熊近身揮擊對照刺蝟尖刺，完成 [v0.2 角色對照 PoC](animal-attacks-poc-v0.2.md)。這是 F03 的實驗角色，正式角色名單與實際體感結論仍待收斂。

- 首輪使用者試玩回報「目前測試起來 OK」，認可簡單、快速 PoC。後續要求完整主題／故事與 UI／美術、震動等回饋，以及不同動物的攻擊特色；刺蝟射擊為其中一種打法。詳見 [回饋與後續事項](poc-feedback-and-followups.md)。

- 已確認：Q1–Q15，包括手機方向、角色特色、操作節奏、首個角色、資源、原型範圍、成長、敵人、受傷、視角、短版終點與協作方式。
