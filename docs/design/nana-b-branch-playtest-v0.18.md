# 奈奈 v0.18 試玩提案：紅怪追上來後，B 有兩種選擇

2026-11-18，已依使用者確認實作，待真人試玩。依據為 [v0.17 試玩回饋](poc-feedback-and-followups.md#v017-成長與重玩回饋2026-11-18)。

玩家已感受到 A、B 操作有別，也記得紅怪追擊。這輪想知道，選了 B 的玩家看過另一種打法後，會不會自己想再開一局試它。

## 戰鬥與選擇

森林短局中，選到 B 三級時，用同一次升級在兩個效果間擇一，可先查看兩者說明。沿用 B 的蓄勢方式與二級推開規則。

| B 三級選項 | 戰鬥效果草案 | 紅怪逼近時的決定 |
| --- | --- | --- |
| 雙發蓄勢（現有） | 最多存兩發。蓄勢爪命中後消耗一發。 | 現在推開追兵，還是多繞一段存第二發，以便連續清出退路？ |
| 回身追咬（新） | 最多存一發。蓄勢爪推開敵人後，在仍存活的被推目標中，取最接近瞄準中心的一隻，短暫顯示咬擊記號。若下一次爪擊在 2 秒內命中它，追加一次單體咬傷。先以一次普通爪擊的基礎傷害試調。 | 已經拉開距離，要繼續撤走，還是冒險追上剛被推開的紅怪補咬？ |

追加傷害限一次，沿用手動移動與瞄準。記號逾時、目標死亡或換段就消失。用獨立記號和傷害事件處理，C 的獵痕、蓄咬與兌現只依既有規則運作。兩秒與傷害皆為試調值。開發端先確認正常走位下追得到紅怪，單靠原地持續攻擊也不會經常白拿回報；否則先修追擊距離或觸發條件。

## 試玩與決策

開發端先用相同候選種子、相同第二核心與相同紅怪場面比較兩條路，確認效果可觸發、玩家看得清目標，並檢查兩條路的生存與傷害差距。真人試玩沿用四段短局，B 起手，自由選一路。抵達結算後讓玩家自行決定下一步，再詢問原因。若沒有取得 B 三級，該局只提供分支出現時機的資料。

- 玩家主動重開並嘗試另一條路，而且能描述不同的走位或出手時機，才有理由擴充同核心的分支。
- 兩條路都想試，實際操作卻很像，先修能力與遭遇的互動。
- 打法有別，但結算仍缺少期待，下一輪以同一個已驗證效果做一次「帶回鈴鐺、下局裝備」實驗，比較收藏是否增加再開一局的意願。

這次觀察的是當下再玩一次的理由。長期重玩仍需要跨日與多局試玩。
