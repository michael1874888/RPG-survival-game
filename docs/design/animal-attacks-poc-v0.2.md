# 動物攻擊差異 PoC v0.2

日期：2026-11-14。對應首輪回饋 F03。狀態：原型與 APK 已完成，已收到小熊首輪操作回饋。

## 要回答的問題

在相同的移動、手動瞄準輸入，以及相同敵人規則下，換成近身揮擊角色，能否讓玩家自然改變接敵距離、站位、攻擊時機與升級選擇？

開發端先選小熊作為比較用角色，利用熊掌揮擊建立與尖刺不同的攻擊行為。這是可調整的實驗角色，不代表已確定正式角色名單。沿用既有 Godot 原生原型，入口仍是 Play.command 與 Android APK。

## 本輪可玩內容

| 面向 | 小刺蝟 | 小熊 |
| --- | --- | --- |
| 攻擊 | 朝瞄準方向發射尖刺 | 朝瞄準方向進行近距扇形揮擊，不生成投射物 |
| 基礎節奏 | 每 0.42 秒發射 | 每 0.70 秒揮擊 |
| 基礎傷害 | 每根 13 | 每次揮擊對範圍內每個敵人 30 |
| 距離與範圍 | 尖刺飛行距離受速度與壽命限制 | 118 距離、120° 扇形，判定包含敵人半徑 |
| 空間控制 | 以距離、方向及投射物覆蓋清群 | 命中存活敵人後擊退 75，短暫停頓 0.16 秒 |
| 專屬升級 | 散射、穿透、反彈 | 揮擊角度、揮擊距離、擊退距離 |
| 共通升級 | 傷害、攻擊頻率、移速 | 傷害、攻擊頻率、移速 |

兩個角色生命與基礎移速一致。所有數值均為實驗起點，不是平衡結論。敵人使用同一套行為與生成規則，隨機內容及玩家路線可能不同；本輪不以擊敗數直接評定角色優劣。

主選單提供角色卡片，開局後使用相同輸入：左側移動、右側瞄準並持續攻擊。重新開始保留所選角色，但清除本局升級；回到主選單可換角色。HUD、升級卡片與結算會顯示對應角色／能力。

小熊升級規則：角度每級增加 24°，最多兩級；單次傷害除以 `1 + 0.12 × 角度升級級數`。距離每級增加 18、擊退每級增加 28，兩者最多三級。專屬選項達上限即退出候選池。小熊不會抽到尖刺專屬選項。

## 已驗證

- 57 項規則檢查及 16 項場景流程檢查通過，共 73 項。
- 新增檢查包含前方扇形與距離判定、背後／遠處不受傷、實際擊退、死亡只計分／掉落一次、角色升級池、上限退出、選角、升級介面與重玩保留角色。
- 刺蝟既有三分鐘整合模擬仍通過。
- 小熊另外以固定 seed 901、測試專用自動輸入與無敵模擬三分鐘，達到成功、77 次擊敗與 5 次升級，全程沒有投射物。這是流程遍歷，不是人類難度或爽感驗證；實際遊戲沒有套用該無敵輸入。
- Mac 原生視窗已查看雙角色卡片、小熊開局、移動、手動攻擊及失敗結算；未見遊戲程序錯誤。
- Android v0.2.0／versionCode 2 APK 已匯出，ARM64、簽署、Manifest、ZIP 完整性、測試程式排除與字型授權檢查通過，沒有要求 Android 權限。

UI／美術與主題故事 F01、震動回饋 F02 仍依後續階段逐步規劃。

## 使用者試玩回饋

使用者表示小熊攻擊距離較近，操作要求較高；較高的基礎攻擊力能補償，因此覺得「還可以」。暫記為近戰風險與傷害回報初步可接受，未據此調整數值，也不視為完整平衡驗收。此次回覆未指定測試設備或平台。

使用者另希望未來加入家中黑貓與約克夏，原始行為特色已記入 [回饋與未來角色候選](poc-feedback-and-followups.md)。

## 請比較這三件事

1. 兩種角色各玩 1–2 局：換成小熊後，你是否自然想靠近、退開或繞到不同位置？
2. 小熊的揮擊範圍與冷卻間隔是否容易理解？是否能分辨打空、命中與擊退？
3. 角度、距離、擊退三個方向中，哪一個最能改變打法？有沒有只是更危險、卻沒有更有趣的部分？

若差異有意義，再研究另一種攻擊行為或深化構築；若距離與風險不舒服，先調整範圍、節奏或提示。正式角色與美術仍依試玩結果收斂。
