# 奈奈 v0.9 設計重新盤點與競品對照

日期：2026-11-14。**狀態：研究與 review 提案，待使用者決策；本輪沒有變更遊戲規則或 APK。**

盤點對象是目前工作區的 v0.9 原型，並非 Git HEAD 或完整十分鐘版本。依據包括現行程式、既有設計文件、使用者本輪試玩回饋、官方資料與一項新增的受控戰鬥探針。競品未在本輪安裝實玩；手機效能與真人平衡未重新量測。

## 1. 判斷：主方向可保留，專精結構與驗證方式需要修正

單一黑貓角色、移動中攻擊、局內成長、主動冷卻大絕，以及有預警與反擊空檔的敵人，仍能組成一致的生存動作玩法。使用者已回報成長模式後期還可以，這是值得保留的正向證據，但未涵蓋所有階段和路線。

目前最大的風險是：**我們將「擅長集中處理強敵」實作成「主要普通攻擊失去多目標能力」，卻沒有同步建立可靠的清路配套、目標交付與足量的強敵收益。** 單點比較吃力可以是差異，但不能作為設計已合理的理由。

推薦先把兩路設計成「都具備基本生存與清路能力、各自強化不同戰鬥循環」，再確認整場挑戰會讓兩種強項都有用途。這是本專案的推薦方向，不是從競品得出的必然成功配方。

## 2. 我們要做的體驗，以及目前做到哪裡

使用者已確認：手機橫向雙手操作、可愛動物與誇張非血腥戰鬥、局內構築與清怪爽感；第一版聚焦奈奈，保留其他角色擴充。抓、咬是特色來源，能力可以延伸；主動大絕與冷卻是必要條件。來源：[方向紀錄](game-direction.md)、[戰鬥草案](nana-combat-design-v1.md)。

| 時間尺度 | 希望玩家做的事 | 現行狀態與判斷 |
| --- | --- | --- |
| 數秒 | 移動、瞄準、切開缺口、抓住強敵空檔 | 已成立的操作骨架；狩獵選敵及清路的回報仍不足以定案 |
| 數十秒 | 承受怪潮、收經驗、升級、安排大絕 | v0.9 已有成批生成與減量；仍需分辨喘息、空等和強勢期 |
| 一局 | 選主打法、成形、應對混合敵人與終點 | 四分鐘成長試驗；完整十分鐘與 Boss 未實作，不能視為完整局已驗證 |
| 重玩 | 換打法後改變站位、目標與升級優先順序 | 主專精已改招，但後續主要仍是數值選擇；目前能否支撐重玩未知 |

使用者最新回饋分開記錄：①成長模式後期還可以；②同密度比較模式中單點較吃力。未指定比較的是原版、快攻或重擊，也未提供設備、受傷／擊殺時間與多局紀錄，因此不推論三種單點都一樣弱。

## 4. 現行設計的主要問題

### A1：選狩獵可能同時失去清群、控場與成長效率【優先修正】

基礎爪擊原本可打扇形內多個目標；掃群擴角且每第三次環掃。狩獵改成只取一個目標，快攻將間隔縮為 0.28 秒，重擊則提高至 21 傷害。程式：[攻擊與擊退](../../game/scripts/nana_combat.gd:67)。

掃群每次打中多隻時，同時處理多份生命，也推開多隻追逐者。這會產生更多安全空間、較少接觸風險及更方便的經驗拾取；這些是由現有規則推導的收益，並非本輪已量測的真人差距。

狩獵的短處則每個怪包都可能發生，較快處理強敵的回報只在適合的目標與時機出現。若只繼續增加單體傷害，可能把精英打得過快，卻仍沒有解決換敵與包圍。設計需要先決定狩獵整套能力如何保持清路底線。

### A2：狩獵的選敵與重咬還沒有充分支撐「集中打威脅」【優先修正】

目前選敵按瞄準中心線優先，同角度再取近者；不是最高生命、最近目標或特殊敵人自動優先。標記是命中後短暫顯示，沒有持續鎖定功能。來源：[選敵](../../game/scripts/nana_combat.gd:151)。

咬擊蓄滿後在下次合法出手自動追加，玩家能轉向或停手保留，但沒有獨立指定咬擊目標。狩獵還要同時完成近戰接近、窄角瞄準和閃招；目前無法只憑紙面單體輸出宣稱已獲得足夠補償。

**推薦：**先確認手機上能否可靠把攻擊交給想處理的威脅，再決定是否需要目標提示、選敵黏著或咬擊時機調整。此處不預設要新增按鍵或全面自動選敵。

### A3：比較模式的取樣與控制不足【先修正驗證方法】

| 現行規則 | 會漏掉的事情 |
| --- | --- |
| 怪潮比較 90 秒，精英到 150 秒才可排入 | 比較模式不可能出現精英，無法測完整的精英收益 |
| 守衛到 80 秒才加入隨機候選 | 最後十秒也不保證有守衛；大部分體驗仍偏向處理普通追兵 |
| 固定基礎能力，成長模式則有升級 | 能診斷核心短處，但不能直接推論後期流派表現 |
| 同一種子與出怪規則 | 擊殺、容量、走位取消與重試會改變亂數消耗及實際遭遇，不是逐隻相同的生成錄影 |
| 原本密度／新版怪潮 | 兩者還改變特殊敵人排程、重試與容量計算，不是只變一個密度參數 |

來源：[時長](../../game/scripts/run_model.gd:63)、[特殊敵人與精英排程](../../game/scripts/nana_encounters.gd:191)、[固定種子入口](../../game/scripts/main.gd:274)。舊的固定精英情境仍可補充觀察，但沒有同時提供持續怪潮與成長。

**推薦：**用清群、混合威脅、強敵與支援小怪、完整成長四種問題分別取證。比較主攻時安排可核對的固定事件；評估流派時保留完整成長與走位。使用者不用代替開發端記錄秒數或重複測完整矩陣。

### A4：敵人分工合理，但混合遭遇與終點收益尚未完整【保留骨架、補足配置】

追逐、衝撞、投擲、守衛、雙段精英，分別提供群體接觸、方向閃避、遠距干擾與反擊空檔，符合奈奈的機動近戰。可見一段時間後才啟動攻擊、預警鎖定、並發限制等規則值得保留。來源：[敵人定義](../../game/scripts/nana_encounters.gd:6)、[動作流程](../../game/scripts/nana_encounters.gd:248)。

但目前特殊敵人多是時間到後隨機抽一種，沒有明確編排「威脅出現 → 玩家可接近 → 成功解決後場面改善」的遭遇。成長挑戰要求四分鐘存活且精英已死；精英從 150 秒開始，擊殺快慢主要影響剩餘壓力，沒有更快結束或不同節點獎勵。這不一定需要額外獎勵系統，但需要讓消除威脅本身有可見價值。

草案寫精英登場停止補普通守衛；現行新排程的 guard 上限仍獨立計算，精英在場時並未排除 guard。這是要一起盤點的規格落差，不應把完整一局的遭遇限制視為已落實。來源：[草案敵群限制](nana-combat-design-v1.md)、[現行候選池](../../game/scripts/nana_encounters.gd:193)。

### A5：成長後期改善，可能部分來自跨越擊殺門檻【需分階段量測】

追逐者生命 18；快攻普通爪擊 14。兩次強健後為 `14 × 1.30 = 18.2`，可從兩次普通爪擊變為一次；零強健的重擊 21 本來就跨過門檻。這是現行規則的靜態推算，不表示已確定使用者那局選了什麼。來源：[升級](../../game/scripts/run_model.gd:33)、[敵人生命](../../game/scripts/nana_encounters.gd:6)。

這能提出一個合理解釋：固定能力的快攻比較吃力，成長後期則舒服一些。必須記錄升級與擊殺門檻，才能區分「流派已成立」和「數值終於補到基本清怪需求」。

目前 Lv.4 提供一次主專精，後續主要是角度、距離、傷害、頻率與生存。保留這些共通升級合理，但尚不足以證明兩路有不同的後續構築。應先讓主專精成立，再各設一個真正改變觸發／目標／節奏的後續選擇；不先增加多層樹。

### A6：大絕合理，但不能獨力支付狩獵所有清路需求【保留、補驗用途】

大絕共通效果為啟動衝擊與短暫無敵，接著六秒增距／增傷，40 秒冷卻。這提供救場與進攻的選時機空間，符合已確認方向。來源：[大絕](../../game/scripts/nana_combat.gd:123)。

影化仍維持單目標限制；範圍增長對掃群的多目標覆蓋和狩獵的選敵距離，收益不同。若狩獵每遇普通包圍都只能等待大絕，它就缺少日常對策。需要觀察兩路實際將大絕用在何處、冷卻期間怎麼走出包圍，而不是先加冷卻縮減或全畫面清場。

### A7：密度要服務接敵與節奏，不能只追場上總數【保留 v0.9、調整判準】

v0.9 的成批生成、安全取消後重試、容量納入預警／重試，是可保留的改進。但所謂人口 target 實際用於限制本次排入量，並不是持續補到目標；固定日曆減量也不保證當時玩家已受壓。來源：[新版排程](../../game/scripts/nana_encounters.gd:173)。

過往自動無敵流程的平均 4.46–5.33 隻僅是特定控制器的結果。遠方追兵、近身多方向夾擊與特殊攻擊重疊，不能當成同一種壓力；追到 24–36 隻並不自動更好玩。

推薦先用明確排程觀察接敵間隔、附近敵量、可走方向、受傷來源與精英窗口，不急著建立複雜的自適應 Director。競品提供的是設計案例，沒有適合奈奈的通用人口公式。

## 5. 本輪受控量測：單體收益存在，但不能換算成整場平衡

新增[戰鬥探針](../../scripts/research/probe-nana-design-audit.gd)，直接呼叫現行攻擊與咬擊。固定 0.01 秒步進、完美瞄準，敵人靜止且集中於前方 100 距離；每步重設擊退，正常計算破綻。沒有敵人攻擊、走位、出怪、升級、大絕或拾取，八隻追逐者刻意重疊。因此只量測這些理想命中情境，不代表真實清群時間、真人技巧或難度。計時自第一個模擬步開始。

| 靶群 | 掃群 | 狩獵原版 | 狩獵快攻 | 狩獵重擊 |
| --- | ---: | ---: | ---: | ---: |
| 8 隻集中追逐者，全數擊敗 | 0.42 秒 | 4.62 秒 | 3.08 秒 | 2.52 秒 |
| 1 隻守衛，擊敗 | 3.05 秒 | 1.68 秒 | 1.12 秒 | 1.37 秒 |
| 1 隻精英，擊敗 | 8.82 秒 | 4.73 秒 | 3.19 秒 | 3.78 秒 |

這個結果修正兩個過度簡化的說法：狩獵並非沒有單體優勢；快攻／重擊也沒有因紙面普通攻擊比值相同，就在實際連段中相等。但普通怪出現得更常、清群還附帶生存收益時，單體優勢並不必然足以交換整場短處。

```sh

```

本輪沒有重跑整套回歸測試；規則未變，既有 227 項通過紀錄也不當作本輪的平衡驗證。

## 6. 推薦方向與替代方案

**推薦方向：以完整的奈奈能力組作為底座，專精決定重點與循環。** 基礎爪擊負責近身清路，重咬負責重點威脅，大絕負責主動爆發／救場。這三個責任應在兩條路線都可辨認，強弱與運作方式不同。

| 方案 | 具體方向 | 收益、成本與本輪建議 |
| --- | --- | --- |
| **A：保留基本清路，分化爪與咬的循環** | 掃群主打覆蓋與節拍環掃；狩獵保有較窄的基本清路，再把集中輸出、標記或連續追獵放在重點動作 | 延續現有三個動作，新增系統較少。需確保不是又變回「兩路都一樣，只差倍率」；推薦先規格化此案 |
| B：保留單點主攻，另給一種有上限的日常突破手段 | 例如完成指定擊殺後轉移攻擊，或有限穿透／短暫突破；選一種核心規則即可 | 可以保留強烈的單點節奏，但要明確交代觸發、目標與不能連鎖的邊界；作為 A 的小型對照候選 |
| C：維持純單點全套，只提高攻速／威力 | 延續目前數值補償 | 製作快，但普通怪與精英需求差異可能迫使數值反覆拉扯；不推薦作為預設開發方向 |

以上沒有要求新增角色、武器欄、獨立閃避鍵、召喚物、局外養成或正式美術。那些都有可能成為未來內容，但不是本次研究得出的必要解法。A／B 的確切招式與數值仍需先形成可 review 的短規格，不能將本報告視為已批准實作。
