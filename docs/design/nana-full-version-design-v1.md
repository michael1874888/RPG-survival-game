### 設計診斷與回應

目前主要缺口是：**有招式可選，但每局想完成的事、遭遇對打法的要求，以及結束後的下一個計畫，還沒有串成完整循環。** 這是根據回饋與現行程式提出的設計推論。

| 缺口 | 完整版如何處理 | 要看到的玩家行為 |
| --- | --- | --- |
| 戰鬥常只需繞圈清怪 | 有限波次、目標優先順序、兩次可選風險、各有破綻的 Boss | 為了對付某個威脅而換站位、停手或開大 |
| 同一起手很快走成固定答案 | 核心分支、少量修飾、跨核心聯動、有限刷新 | 能說出這局為何改選另一張卡 |
| 拿到物品只想試一次 | 寶物提前成形，格位限制留下配裝取捨；章節揭示下一個可追目標 | 試完後有自己的下一個實驗 |
| 失敗像白打一場 | 新收藏當場保存、解釋致命攻擊、快重開、可續玩 | 知道下局要修正什麼，而非只等永久加傷 |
| 收集完就沒有目標 | 六種打法熟練紀錄、三章不同 Boss、可選高難度 | 願意用熟悉裝備做得更好；也容許玩家滿足地玩完 |

「增加回頭率」的方向是累積值得回來的計畫。首發採完整離線本體，局外進度以解鎖玩法為主；不靠體力、連續登入或無上限戰力成長安排遊玩時間。

## 2. 遊戲定位與特色

**一句話：**操作黑貓奈奈在夜間庭園抓開敵群、重咬強敵，依這次機會組出狩獵方式，把撿到的小寶物帶回家，再帶著新習慣出門。

- **目標玩家：**喜歡動作、構築與收集，願意主動瞄準，但不想在手機管理大量按鍵；典型情境為一次能投入約一局的休息時間。目標不是純放置玩家。
- **平台：**手機橫向雙手優先；Android 先交付試玩，同一套內容以 iPhone 首發品質製作。Godot 4.7.2／GDScript 沿用；實際最低裝置與 OS 經效能測試後鎖定。
- **第一個記憶點：貓的狩獵節奏。**連抓維持攻勢、停手遊走換爆發、認定獵物後重咬；所有能力仍能看出抓、咬與影子的來源。
- **第二個記憶點：小寶物改變下次的成長計畫。**出門裝備提供提早成形，局中選項決定如何發展，格位讓熟悉裝備仍有取捨。
- **第三個記憶點：自選冒險。**能為尋寶多冒一次風險，也能保留血量挑戰守關；風險和可能回報在選擇前顯示。

首發集中一位角色。其他動物留給下一版；三個章節、不同狩獵方式與敵人應對承擔首發變化量。這是範圍選擇，是否足夠由完整試玩判定。

## 3. 三層核心循環

| 尺度 | 玩家實際做的事 | 回報 |
| --- | --- | --- |
| 數秒至半分鐘 | 瞄準清路、誘招、停手蓄勢、咬住強敵、用大絕突破 | 看懂危險並成功處理的控制感 |
| 一局 | 選兩個核心以內的構築、比較升級、作兩次路線選擇、擊敗守關 | 一套這次親手形成的打法、新收藏或挑戰成果 |
| 多局 | 指定尋寶目標、換裝測試、開下一章、練另一成形與難度 | 「我知道下一次想試什麼」；最終有清楚的完成狀態 |

```mermaid
flowchart LR
    A[選章節、起手與兩格裝備] --> B[清路與拾取成長]
    B --> C[三選一塑造打法]
    C --> D[休息或冒險的路線選擇]
    D --> E[精英與守關驗證構築]
    E --> F[帶回收藏、回看成敗]
    F --> G[選擇下一個想試的計畫]
    G --> A
```

## 4. 一局的完整結構

每次遠征只選一章，不必連打三章。一章為完整一局；目標作戰時間約 8–10 分鐘，含升級、看裝備與休息約 10–12 分鐘。這是調節目標，沒有十二分鐘到就判死的規則。

| 戰鬥節點 | 用途 | 經驗預算 | 完成後 |
| --- | --- | ---: | --- |
| 1 | 開路，第一個成長回報 | 18 | 升級／前進 |
| 2 | 加入本章第一種混合威脅 | 24 | 升級／前進 |
| 3 | 第一精英，驗證起手 | 42 | 收藏箱、營地一、成形資格開放 |
| 4 | 執行營地一選定的路線事件 | 54 | 結算該事件的收益 |
| 5 | 本章的代表性混合遭遇 | 60 | 升級／前進 |
| 6 | 第二精英，驗證組合 | 66 | 收藏箱、營地二 |
| 7 | 執行營地二選定的路線事件 | 60 | 結算該事件的收益 |
| 8 | 讓成形能力有實際發揮的戰鬥 | 66 | Boss 預覽、最後整理 |
| 9 | 本章獨立 Boss | 0 | 勝利、章節成果、結算 |

### 戰鬥的開始與結束

1. 普通節點為三波有限敵人；前波全清就補下一波，否則在第 20、40 秒補齊後續波。必要波次敵人及所選事件的必要目標全數擊敗即完成，召喚物隨節點完成消散。強構築能提早結束，不必空等倒數。
2. 普通節點調節目標為 45–60 秒；精英節點為 45–60 秒；Boss 為 60–120 秒。超時只記錄調節資料，不憑空造成死亡或無限生怪。
3. 精英節點是指定精英與有限護衛；清完才通過。Boss 生命歸零立即取消剩餘攻擊、清除支援，進入結算。
4. 同一模擬步先處理玩家本次攻擊與 Boss 死亡，已擊敗的敵人取消未結算攻擊；再處理仍有效的敵方傷害。玩家與 Boss 同步達成致死條件時按此順序判定，不隨畫面更新率改變。
5. 節點完成後暫停時間，自動收回地面剩餘經驗。下一戰須主動按前進；一般轉場沒有額外補血。
6. 每章固定槽位各有兩套遭遇編排，出門種子決定其中一套；同一局不臨時依玩家變強而增加血量。營地事件可以明示地替換下一戰編排。
7. 關卡可解條件包含敵人能走到玩家附近、所有必要敵人可攻擊、出口可達；卡住的生成先安全重排，不能讓玩家因模型錯誤被困住。

### 營地與路線

- 節點 3、6 後各一個營地，先恢復 25 生命，上限為當前最大生命；大絕冷卻不因看選單而流逝。
- 每次提供兩個不同事件：一個普通風險、一個明示的額外挑戰。預覽下一戰的敵人、場地變化、額外條件及獎勵後選一個；沒有略過主戰鬥的捷徑。
- 兩個營地不重複同一事件 ID；六個事件的完整效果見[內容表](nana-full-version-content-v1.md)。未選事件的條件及收益都不生效。
- 選擇低風險仍取得該戰完整經驗及主線獎勵。高風險回報偏向新收藏機會、補給或選項修正，避免把基本戰力藏在可選挑戰裡。

## 5. 基礎戰鬥與共同計算

以下作為完整版統一後的起點；多數沿用原型，並非宣稱現行所有路徑已使用同一傷害公式。能力個別效果見內容表。

| 項目 | 規則與起點 |
| --- | --- |
| 生命與移動 | 100 生命、移速 260 世界單位／秒、碰撞半徑 20；移動與攻擊可同時進行 |
| 一般爪擊 | 持續按右側瞄準區時每 0.42 秒出手一次；傷害 10、距離 145、總角度 100°；一爪每敵至多一次 |
| 重咬 | 三次有效爪擊各得一格；同一爪命中多敵仍只得一格。滿三格後，下一次有合法目標的攻擊追加重咬；傷害 14、距離 175、總角度 55°、前搖 0.1 秒 |
| 咬擊準備 | 沒有合法目標就保留；一旦開始前搖便消耗三格。目標死亡／離開範圍則落空，不自動改咬遠方敵人。爪擊先結算，咬擊再鎖仍存活的合法敵人 |
| 瞄準輔助 | 優先瞄準方向內的獵痕目標，其次依方向與距離、有限特殊敵偏好選擇；預覽與實際前搖共用同一鎖定結果 |
| 普通爪擊推開 | 存活追逐者／疾追者推開 12 世界單位，不提供對全體敵人的永久硬控 |
| 夜影解放 | 主動按鍵；啟動衝擊傷害 15、半徑 220，推開普通追兵 80；0.6 秒保護，6 秒內爪與咬距離 ×1.4、直接攻擊傷害 ×1.5；從啟動起冷卻 40 秒 |
| 受傷 | 每次受傷後保護 0.8 秒；同一時刻多個敵方命中只結算其中最大傷害。大絕保護與受傷保護取剩餘較長者，不相加 |
| 跨戰保留 | 生命、經驗、構築、大絕剩餘冷卻、咬擊格數、B 蓄勢保留；A 連擊、待發攻擊、獵痕、追咬指示與臨時加成清除；夜影持續時間轉場結束 |

**傷害：**基礎值含蓄勢等固定加值／C 兌現替換值 → 同類百分比相加 → 夜影倍率 → 敵方減傷 → 扣血。沒有暴擊亂數。修飾若只影響爪影或下一爪，不擴張到其他攻擊。生命、冷卻與傷害保留小數計算，畫面只負責顯示。

**速度與控制：**移速加成合計最多 +25%；攻速只縮短一般出手間隔，不縮敵人預警、重咬前搖或大絕動畫。減速同類取最強，普通敵上限 50%；Boss 減速最多 15%、擊退距離僅普通值 20%，不被普通硬控取消完整招式。

**觸發順序：**爪擊 → 蓄勢／追咬追加 → 咬擊鎖定與排程 → 到時結算咬擊／兌現 → 到時結算爪影 → 死亡、掉落、成長。爪影可排入下個模擬步，不能在同一步遞迴觸發另一個自己。

傷害來源分清爪、咬、爪影、追咬、兌現波及、大絕；額外傷害不再產生爪擊次數或重咬格數。聯動只按內容表白名單觸發，每一攻擊／目標的命中去重。沒有目標時的空揮、推到牆上未位移或已死亡目標不冒充成功推開。

## 6. 局內成長：能規劃，也要因局勢改選

### 容量與成長預算

- 出發自選 A／B／C 一個一級核心，免費；第二核心在局中花一次成長取得，最多兩核心。
- 核心最高三級；一局最多一個「成形」，三級時選兩個分支之一。副核心最多二級。正常成形資格從節點 3 完成起開放，未達到前置不出卡；習慣寶物可在對應起手二級提前生效，不受此節點限制。
- 一局最多兩張流派修飾、兩張跨核心聯動；同一張不能重複。共通強化六種，每種最多兩級。這些都消耗同一個成長選擇，不能全部拿滿。
- 從 Lv.1 到 Lv.11 最多十次經驗成長；逐級所需經驗為 **12、18、24、30、36、42、48、54、60、66**，合計 390。節點 1–8 的經驗預算正好提供十次；Boss 前能用完構築。EV05 的額外共通強化獨立記錄，一局至多再多一級，不提高玩家等級或天賦上限。
- 每個節點按預算分配有限敵人的掉落，餘數由最後一個必要敵人攜帶；召喚／事件額外敵人不產經驗，不能無限刷。
- 自行少拿地面經驗會暫時延後升級，但完成節點後自動收回。超過滿級不再出成長選單，也不生成永久資源。

**典型分配：**起手核心到三級花兩次，副核心到二級花兩次，兩張修飾、兩張聯動花四次，剩兩次補共通。可以犧牲部分聯動換生存；不假設所有玩家必須照此分配。

### 候選與補救規則

1. 每次暫停給三個不同、立即合法且有效的選項。核心升階若有兩分支，先選該核心，再確認分支；只扣一次選擇，取消返回原三張。
2. 三個位置依序優先提供：已持有核心的合法下一階；可用的流派修飾／空位可加裝核心；跨核心聯動／共通強化。不足時從其他合法類別補齊，不補已滿或無作用卡。
3. 同一類別內等權、無放回抽樣；核心下一階有兩種時交替優先。核心、修飾、聯動依前置開放，不靠永久抽到某張卡才進牌池；開局可直接使用全部三核心，六個正常三級分支也不需收藏解鎖。
4. 前兩次成長至少一次能看到可用的行為修飾或核心升階；取得二級核心後、成形資格開放時，接下來兩次升級內至少一次提供該核心的三級機會。玩家可以拒絕，不保證三個願望同時出現。
5. 每局有兩次「刷新一整組」機會，上限四次；刷新保留強制候選類別，優先排除上一組卡。若可選內容不足以全換，明示會保留部分，不花資源假刷新。
6. 不喜歡可以「略過並回復 10」；消耗本次成長。滿血時明示本次不會變強，仍可自行略過，不能藉略過洗掉進度。
7. 兩個營地合計可調整一次非核心天賦：花一次刷新，退回一張修飾／聯動或一級共通，立刻三選一重新投入。取消不扣；確認前不移除舊效果。核心、成形及出門裝備本局不重置；原退回選項本次不再出現，除非合法候選不足三張，則先明示再供玩家決定是否調整。
8. 關卡、成長、事件、收藏箱使用獨立種子串流；走位不改變未來升級的抽選序列。續玩保存已生成候選及各串流狀態，不能重開應用洗卡。

完整牌表是 **12 張流派修飾＋6 張聯動＋6 種共通**，不把同卡等級或核心分支重複計入「24 種」。條件未滿不展示，避免未持有 B 卻拿到只對蓄勢有效的廢卡。

## 7. 裝備與收藏：新東西值得帶出去

### 兩個有分工的格位

| 格位 | 功能 | 必須作的取捨 |
| --- | --- | --- |
| 習慣寶物，一格 | 六件，分別對應六種成形；指定起手升二級時提前開啟其成形，並占用本局唯一成形名額 | 提早一個成長點且路線可靠，放棄局中再選成形的彈性，也放棄其他習慣寶物 |
| 隨身小物，一格 | 六件，調整續戰、拾取、移動、大絕或修正機會 | 必須按本次弱點選一件，不能把保護、速度、刷新全帶上 |

習慣寶物只配對應起手；切換起手前顯示這件本局不生效，可換裝或空格出發。配戴時從出門就預留成形名額，二級才生效；副核心不會偷偷取得另一個三級。

回身鈴鐺保留 v0.19 的「B2 提前追咬、單發、占用成形」價值；其他五件使用同等投資規則。這是有意的永久可用性收益，不能假稱與空裝等強。六分支不用寶物也都能以正常投資取得，基本通關不能要求先刷裝備。

### 取得與保底

- 新存檔直接持有兩件通用小物 U01、U02；習慣格為空。首次完成首章節點 3 保證取得回身鈴鐺，沿用既有實驗的清楚收穫。
- 此後節點 3、6 各有一個收藏箱；從所選章節的可尋寶池提出最多三件**未持有**物，選一件永久收藏。後章包含較早的物品，回首章不會得到後章專屬物；確切池見內容表。只有一／兩件時照實顯示，不湊假選項。
- 出發可指定一件已揭示取得地點的寶物為尋寶目標。若該件在本章目前可用池內且未持有，下個普通收藏箱必含它；箱內仍有其他候選，玩家可改選。
- 首章回身鈴鐺的首次保證優先於指定目標；介面提前說明。可用池依章節通關解鎖，不能藉選擇未開放章節或調時鐘取得。
- 事件箱同樣排除重複，但不消耗也不取代普通箱的指定目標保證。沒有稀有度、隨機詞綴、升星或重複裝備數量。
- 選定即存檔；本局不替換出門裝備。現在取得是下一次的新計畫，當局戰力來自成長與路線補給。結算讓玩家自行選擇是否回家換裝。
- 該箱可用池已全持有時，改提供當局有效補給：回血 20、當前大絕冷卻減少 8 秒、刷新 +1。只顯示有效者；若全無效就顯示本區已收藏完成，直接前進，不產生無用途貨幣。
- 取得後死亡、退出、強制關閉都保留；第三段前死亡則沒有該箱。落盤失敗不能顯示永久成功，處理見續玩規則。

**為何採定向尋寶：**讓「我想試哪一件」能轉為實際行動。隨機的是途中可考慮的另一個機會，並不讓想玩的打法被低機率綁住。收藏能完成；完成後重點轉到構築與熟練。

## 8. 敵人如何讓選擇有價值

三章使用不同的威脅組合與場地動線。每個核心都具備清群與處理單體的基本能力；章節只偏向不同選擇，不設「帶錯流派就免疫」的敵人。

- **清群與開路：**普通追兵提供成長與清怪回報；少量疾追者讓單純全速後退不是完整答案。
- **目標優先：**投擲、設陷、呼群、掩護敵人讓玩家比較先清眼前，還是切進去處理後方。
- **爆發窗口：**衝撞、守衛和 Boss 都有可讀前搖與收招；大絕既能救急，也能用來把握輸出窗口。
- **風險由玩家選：**事件前明示增加哪種敵人、需要站哪裡或是否有限時額外目標；挑戰失敗不撤銷已完成主線戰果。

首發八種普通敵、兩種精英、三個獨立 Boss 的數值、招式及混合限制只在[內容表](nana-full-version-content-v1.md)維護。壓力目標是需要讀局勢，同時留出能清掉一群敵人、享受成長的窗口。

## 9. 跨局目標與完整終點

1. **主線：**通過庭院 → 溫室 → 鐘樓三章，取回三件家中失物；第三章完成即有結尾與可回看的章節紀錄。劇情以出門一句、首通一幅簡單畫面／短文呈現。
2. **收藏：**十二件寶物全部真實可得，圖鑑顯示效果、限制及來源；選定一件可直接導航到可尋地點。已完成區域明示完成，不假造無限進度。
3. **熟練：**六個成形各完成任一章可獲一個狩獵記號；需該局實際觸發成形效果一次，不能只裝著卻沒用。
4. **挑戰：**每章有標準、夜巡、深夜三級，逐章通過前一級才開下一級；進階修改見內容表。寶物都可在標準難度取得，難度獎勵為紀錄與徽章。
5. **十八項成就：**六個狩獵記號、九個章節難度通關、三項探索。成就不額外加永久傷害；一局可同時完成多項。

預期主線首通約 45–90 分鐘、探索不同打法約 2–4 小時起，都是待測的內容量假設，不寫成商店保證。完整遊戲可以玩完；希望留下的玩家繼續研究打法，不能把所有離開都當作設計失敗。

## 10. 失敗、退出、續玩及資料保護

| 情況 | 規則 |
| --- | --- |
| 死亡 | 本局結束，局內經驗與天賦清除；新收藏、章節成果與已完成成就保留，出門裝備不掉落 |
| 主動放棄 | 清楚確認放棄當局成長；已落盤收藏保留。可以選暫存離開，無須為生活中斷受罰 |
| 鎖屏／切背景 | 即時暫停，保存當前狀態；回前台先顯示繼續，不在背景計時或自動受傷 |
| 程式被終止 | 從最近有效戰鬥快照續玩，最多回退約 5 秒；保存敵人、攻擊排程、血量、時間、掉落、候選與亂數狀態，不免費重置成滿血 |
| 戰鬥結束／選卡／領寶物 | 關鍵交易立即保存；獎勵以局 ID、節點 ID、獎勵 ID 去重，回退快照也不能重領 |
| 保存失敗 | 保留前一份有效存檔與記憶體狀態，明示尚未保存並允許重試／暫停。新收藏確認成功後才顯示已永久保存，不偷偷清空舊資料 |
| 版本更新 | 檔案帶版本，先驗證再遷移；v0.19 既有鈴鐺所有權與裝備偏好遷移成 H03，不要求玩家重新取得 |
| 備份與清除 | 設定提供本機存檔匯出／驗證後匯入；清除收藏是獨立二次確認。解除安裝或清資料仍可能移除本機進度 |

首發不依賴帳號或伺服器。診斷只留有上限的本機摘要，玩家主動匯出才交出資料；雲端同步是後續版本選項。

## 11. 足夠好的呈現與操作

第一版美術目標是**一致、清楚、有角色感、完整可用**。沿用簡單 2D 也可以，但角色、敵人和寶物必須有完成的辨識造型；不能用會誤導玩家的占位內容冒充可發布品質。

必要交付：

- 奈奈的移動、抓、咬、受傷、夜影、退場各能辨識；敵人輪廓與攻擊意圖不只靠顏色。
- 爪與咬的命中範圍和提示一致；獵痕、追咬與成形可用狀態可分辨；高威脅預警顯示在裝飾之上。
- 左移動、右瞄準／攻擊、大絕三種主要操作；暫停與大絕不搶走正在移動或瞄準的觸控歸屬。提供控制區大小與位置調整。
- 有受傷、成功爆發、成長、收藏、守關攻擊的基本音效；音樂與音效音量獨立。震動、震屏、閃光可關，低效果模式仍看得到危險。
- 準備畫面能同頁看懂章節、起手、裝備與限制；結算只有清楚的戰果、致命來源、再挑戰、回家換裝和離開。
- 新手先玩再學：首戰低壓認識移動與爪，第二戰介紹追咬／蓄勢等起手行為，第一個精英前提示大絕；不在首次開局塞完整圖鑑。練習場可隨時重看敵人與已解鎖裝備效果。
- 必備畫面為首頁／繼續、出發準備、戰鬥 HUD、升級、營地、收藏箱、結算、收藏與紀錄、設定／說明／製作名單。高級動畫、大量粒子、皮膚與完整劇情演出留待第二版強化。

## 12. 玩家連續三局的例子

這是說明規則如何交互作用的例子，不是保證所有玩家都照此遊玩。

**第一局：**B 起手，想先穩定打到守關。第一個精英後拿到鈴鐺；血量偏低時選休息路線。後來仍選雙發清群，守關失敗，結算看見已保存的新裝備與致命招式。

**第二局：**裝鈴鐺後，原本的 B3 追咬能在 B2 就用。省下的成長投入 C 與「蓄勢命中獵痕」聯動；這次不拿第二張清群修飾，改補伸展，讓追擊守關的距離舒服。目標變成驗證早成形如何影響投資，並嘗試通關。

**第三局：**玩家通過首章，下一章揭示較多遠距與封路敵人。帶上新取得的 A 習慣寶物，改玩持續爪影，副核心仍可選熟悉的 B；若途中拿到對咬擊有用的機會，也能轉投 C。這次追的是新的威脅和構築問題，不只看下一個獎勵圖示。

如果第二局結束後仍然沒有想做的事，就回頭修正構築與遭遇，不把第三局的例子當成實際成立的結果。

## 13. 範圍、取捨與主要風險

| 設計取捨 | 可能損失 | 為何仍推薦／如何驗證 |
| --- | --- | --- |
| 一位主角、六個成形 | 角色切換的新鮮感較少 | 集中把每種狩獵節奏做好；若玩家只認得同一招換倍率，先重做效果 |
| 十二件固定效果寶物，可定向取得 | 收集可以較快完成 | 尊重玩家要試的打法；觀察收藏完成後是否仍想挑戰，不能只延長掉落時間 |
| 習慣寶物提早成形 | 裝備有永久戰力優勢、空裝較弱 | 所有基本章節用空習慣格也需可通關；相同預算比較六件，不只拿鈴鐺與空裝比 |
| 兩核心與有限天賦格 | 不能把每個酷效果都拿走 | 留下真實取捨；觀察玩家是否常為第三張有用修飾放棄原計畫 |
| 有限波次與營地 | 連續怪潮感略減 | 降低空等、讓風險選擇可理解；量測選單時間和戰鬥連續感 |
| 道具本局取得、下局裝備 | 不能立即試剛撿到的新招 | 保留明確跨局計畫；練習場可立即預覽，但不拿預覽當真正開始下一局 |
| 離線完整本體 | 缺少社群及每日活動 | 首發品質聚焦核心；商業模式建議買斷或完整免費發布，價格與商店安排另定 |

最高風險仍是「收藏吸引力成立，但拿掉新物品後戰鬥仍重複」。因此製作門檻必須包含試用後的自主再玩，不能只看開箱後的第一次重開。具體判準見發布計畫。
