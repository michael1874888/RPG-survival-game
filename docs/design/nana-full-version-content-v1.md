# 奈奈第一完整版 D1：內容與規則表

**Status:** approved design; R1 subset implemented · **Updated:** 2026-11-20。

本表屬於已確認的[完整版設計](nana-full-version-design-v1.md)。v0.20 實作 R1 的首章子集；第二、三章及其餘首發內容仍待製作。所有數值仍為 **[ASSUMPTION]**，需要在新局長、新遭遇下重新試玩；實際交付與已知差異見 [v0.20 試玩說明](../development/nana-v0.20-practice.md)。此處定義內容自身數值，共用傷害、容量、經驗與保存方式以主設計為準。

## 1. 三個核心、六個成形

三種核心皆可作開局，三級前保持同一套操作；升三級選分支，不再另花一次升級。習慣寶物能跳過「等到第一精英後才開放成形」的時間限制，在對應起手升二級時提早成形。

| 核心 | 一級 | 二級 | 三級分支一 | 三級分支二 |
| --- | --- | --- | --- | --- |
| A 穿影爪 | 三次有效爪擊產生一道爪影：長 340、寬 90、傷害 8、延遲 0.12 秒；間隔超過 1.2 秒沒有命中或受傷即重置連擊 | 連續爪影逐次為 8／12／16 傷害，最高三層；斷連歸零 | **A-W 寬影掃群：**滿三層時爪影寬度變 180，沿正面清開較寬通道 | **A-E 回聲追擊：**滿三層的爪影於 0.25 秒後在原位置、原方向再出一道 40% 傷害爪影；不再觸發回聲 |
| B 游走蓄勢 | 沒有攻擊且實際移動累積 260 距離，下一爪增傷 12、距離 175、總角度 180°；最多一發 | 蓄勢爪額外推開存活、非獵痕敵人 65；受牆阻擋按實際位移判斷 | **B-D 雙發蓄勢：**可存 520 距離／兩發；每次命中消耗 260 | **B-F 回身追咬：**推開後選最接近瞄準中心線的一名存活目標標示 2 秒，下一爪命中該目標追加 10 傷害；仍最多一發 |
| C 獵痕重咬 | 重咬命中存活、未標記敵人即留下單一獵痕；爪擊命中獵痕額外得一格咬擊準備；再次重咬該目標以 36 傷害兌現並清除標記 | 兌現時向半徑 110 內其他敵人造成 8 波及傷害 | **C-H 緊咬獵物：**兌現後若目標仍存活，保留獵痕 | **C-J 逐隻追獵：**兌現擊敗目標時，把獵痕移到 220 距離內最接近原獵物的一名敵人；未擊敗仍照常清除 |

### 判定邊界

- A 計算有命中的「爪次」，不是命中敵人數。重咬、爪影與額外傷害不自行增加 A 連擊。A-E 的兩道影子各自對每敵命中一次；追加影不能觸發聯動或修飾，原影仍可。
- B 只計實際位移，頂牆、暫停、滑動準備畫面都不蓄勢。空揮不消耗蓄勢；命中才消耗。B-F 標記在下一爪出手時消耗，即使該爪失手；不因額外咬擊再刷新自己。
- B-F 候選不含本次爪擊前已有的 C 獵痕，保留 B2 不推走集中獵物的規則。一次只標一名；同方向時選較近者、再以穩定敵 ID 排序。目標死亡、換戰或兩秒結束就清除。
- C 獵痕不自然逾時；目標死亡、換戰或換標時清除。只有重咬能兌現，追咬追加與兌現波及不算兌現。重新咬其他存活目標會轉移獵痕，不能全場同時標記。
- C-J 傳遞只做一次，不連鎖殺傷；周圍沒有合法敵人便清除。C-H 適合持續對強敵輸出，C-J 適合從耐打小隊一路換獵物；兩者不疊加。
- 獵痕會優先引導合法扇形內的重咬，追咬標記僅提示下一爪的機會，不偷偷改變玩家瞄準。
- 受傷會重置 A 連擊，但不刪除 B 已蓄距離或咬擊格數；瞬間保護期間被攻擊但未受傷不算斷連。

### 六種打法必須有的差異

| 成形 | 玩家主要行為 | 擅長 | 要付出的代價 |
| --- | --- | --- | --- |
| A-W | 貼近可持續命中的敵群，保持爪影節奏 | 多方向壓力下掃開較寬正面 | 受傷／斷連後要重建層數；追散開的敵人較吃力 |
| A-E | 把敵人帶過同一射線，讓兩次影子都打中 | 直線追兵、較大的固定目標 | 移動中的側向敵容易離開回聲位置 |
| B-D | 先遊走準備，再決定連發或保留第二次開路 | 一波接一波的清群與撤退 | 必須停手換爆發，不能取得追咬 |
| B-F | 推開、回身、追上同一目標補爪 | 精英與守關的短窗口 | 單發且追咬會失手；對小怪過量傷害不一定划算 |
| C-H | 盯住同一強敵，抓擊加快咬擊循環 | 耐打單體，少換目標 | 需要安全接近；守關支援怪要另想辦法處理 |
| C-J | 先集中擊敗一個耐打目標，再換下一隻 | 混合小隊與有多個耐打目標的場面 | 對孤立 Boss 沒有傳遞收益，不能持續保留同一獵痕 |

## 2. 十二張流派修飾

每張一次、一局共用兩格修飾；需持有該核心才能出現。未另註明的短效加成重複取得只刷新時間，不堆層。

| ID | 名稱／前置 | 效果 | 會改變的選擇 |
| --- | --- | --- | --- |
| M01 | 續爪／A1 | A 連擊容忍時間 1.2 → 1.8 秒；受傷仍重置 | 允許多繞一步保住連擊 |
| M02 | 聚影／A1 | 原爪影傷害 +35%，延遲 0.12 → 0.25 秒；回聲按改後原影的 40% 計 | 更強但更需要把敵人留在射線內 |
| M03 | 回撥／A1 | 原爪影擊殺至少一敵，下次一般爪距離 +25%，須在 3 秒內用掉；不延長咬或爪影 | 清路後能接上下一群，不只是站著打 |
| M04 | 叩影／A1 | 原爪影命中精英／Boss，咬擊準備 +1；每道一次，內部冷卻 2 秒 | 把爪影與近身重咬接起來 |
| M05 | 輕足／B1 | 每發需 220 距離，但蓄勢固定增傷由 12 降為 8；雙發上限同步為 440 | 小步頻繁開路或長走高爆發的取捨 |
| M06 | 留力／B1 | 蓄勢命中後返還本發門檻的 20% 距離，不超過目前蓄勢上限 | 在較短安全距離內反覆遊走 |
| M07 | 截路／B1 | 蓄勢命中使普通敵減速 30%，1.5 秒；Boss 按共同控制上限 | 退路與追咬窗口更穩，放棄其他輸出修飾 |
| M08 | 直衝／B1 | 蓄勢爪距離 +35，總角度由 180° 改為 120° | 用精準直線交換側面覆蓋 |
| M09 | 餘味／C1 | 獵痕目標被一般爪或原爪影擊殺時，將獵痕傳給 220 內最近一敵；不額外傷害 | 讓清群時較少白白丟掉獵物；不把兌現變成必要條件 |
| M10 | 淺嚐／C1 | 對未標記敵人的普通重咬基礎傷害 14 → 20；兌現仍為 36 | 優先擊殺弱目標或準備長獵的比較 |
| M11 | 掀葉／C2 | 兌現波及半徑 110 → 150，傷害不變 | 把其他敵人引到獵物附近再兌現 |
| M12 | 銜機／C1 | 兌現後下次一般爪傷害 +60%，須在 3 秒內用掉；不增加該爪附帶的追咬／爪影傷害 | 咬後決定繼續對強敵，或轉身清路 |

M09 與 C-J 分別處理「沒有兌現就先死亡」與「兌現死亡」；同一死亡來源只走其中一條。沒有無意義的雙重傳遞。

營地裝卸 M05 時，已有蓄勢按原門檻的比例換算到新門檻，不能藉改門檻免費多一發。短效修飾若被退回，立即取消其待用加成；不刪除已排程且已支付出手成本的攻擊。

## 3. 六張聯動

需同時持有表內兩核心，一次一張，一局最多兩張。效果建立在核心已有功能上，單核心不必等聯動才可用。只有原攻擊能觸發，追加攻擊不再接回自身。

| ID | 名稱／前置 | 明確規則 |
| --- | --- | --- |
| S01 | 借勢成影／A＋B | 蓄勢爪成功命中，對 A 算兩次有效爪擊而非一次；一爪最多產一道原影，多餘次數保留到下一爪 |
| S02 | 影下蓄步／A＋B | 一道原爪影命中至少三個不同敵人，返還 60 蓄勢距離；每道一次，內部冷卻 3 秒 |
| S03 | 影中獵味／A＋C | 原爪影命中現有獵痕，咬擊準備 +1；每道一次，內部冷卻 2 秒 |
| S04 | 咬開影路／A＋C | 兌現後，把「下一道原爪影的起點」移到該獵物當時位置，方向沿玩家產影時瞄準；3 秒內有效，只改起點、不額外生成一道；地形遮擋仍適用 |
| S05 | 蓄勢追獵／B＋C | 蓄勢爪命中本次出手前已有的 C 獵痕，將咬擊準備直接補滿三格；本次爪之後的下一次合法攻擊才追加重咬 |
| S06 | 咬後遊走／B＋C | 一次兌現返還 130 蓄勢距離；內部冷卻 2 秒，不能因波及多敵重複取得 |

同時持有 M04 與 S03 時，原影命中「有獵痕的精英」可各提供一次格數，但總咬擊準備不超過三。這是容許的強組合，仍受各自冷卻、出手次數與格位限制。

## 4. 六種共通強化

每種兩級，每次只升一級，和核心、修飾、聯動共用成長點。沒有另外的永久屬性樹。

| ID | 名稱 | 每級效果 |
| --- | --- | --- |
| G01 | 利爪 | 所有傷害 +10%，同類加成相加 |
| G02 | 伸展 | 爪、咬與爪影距離 +10%；不擴大角度或波及半徑 |
| G03 | 護身 | 最大生命與目前生命各 +15 |
| G04 | 貓步 | 移速 +6%，受共同移速上限限制 |
| G05 | 快爪 | 一般出手頻率 +8%；間隔為基礎間隔 ÷（1＋總頻率加成） |
| G06 | 夜瞳 | 大絕完整冷卻 -4 秒；若正在冷卻，剩餘也扣 4 秒至零，不重置夜影時間 |

退回 G03 時最大生命減 15，目前生命僅壓回新上限，不造成傷害；退回 G06 時若仍在冷卻則剩餘加回 4 秒、至新完整冷卻上限，已就緒則維持就緒。移速與頻率每次都從當前持有等級重算，不以重複相乘增減。

圖鑑鎖定物先顯示效果類型與解鎖章節，來源揭示後顯示完整數值；不顯示假稀有率。尋寶目標跨局記住，取得後清除並讓玩家自由指定下一件。

R1 首章交付的 H01／H03／H05 與 U01／U02／U03 六件均完整可得；其他物不在 R1 介面承諾可取得。完整發布時本表全部完成。

E03–E08 沒有額外接觸傷害，只由列明招式造成傷害。守衛不會憑空擋住所有普通攻擊；減傷只來自可見的 E08 連結。

**打斷：**重咬可打斷 E03／E04／E06／E07 的前搖，令其收招 1 秒；被打斷後 2 秒內不再被同類打斷。守衛收招可延長一次。普通推開不取消已鎖定的遠距招式；離開範圍能讓近身招式落空。

### 混合與公平性限制

- 全場 45 容量包含存活、預警、重試保留與召喚保留；同一敵 ID 不重複占位。有限波次不因重試反覆多生敵人。
- 標準難度同時最多兩個特殊攻擊事件，從前搖到攻擊結束占名額；Boss 大招可占滿兩格，其他高威脅先等待。已飛行的傷害彈仍屬原事件。
- 非 Boss 同場上限：疾追者 3、衝撞者 2、投擲者 2、守衛 2、設陷者 1、呼群者 1、燈靈 1；同時最多三種特殊類型，固定內容表需遵守。
- Boss 場支援最多兩名，從章節指定類型選；沒有第二個 Boss 或額外精英。召喚物仍計入支援上限。
- 傷害彈全場最多 32、危險區最多 6；上述攻擊並發上限通常會先限制它們。到上限延後攻擊，不靜默新增不可見傷害。
- 出生距玩家至少 320，完整預警 1 秒；實際出生時重查，靠太近就另排位置並重新預警。出生後可見至少 0.4 秒才開始特殊前搖。
- 敵人離開畫面不得開始指向玩家的遠距招式；已在畫面內起手的攻擊可以完成，但邊緣仍保留來向提示。
- 每組混合必須有可達退路；場地、藤圈與 Boss 危險區不可同時封死。以靠牆、中央、兩角落及低移速實機情境核對，不能只看理論空隙。
