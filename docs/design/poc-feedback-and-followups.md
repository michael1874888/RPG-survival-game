# PoC 回饋與後續設計事項

更新日期：2026-11-15。來源：使用者逐輪試玩回饋。用途：保留後續階段逐步優化的方向。

## v0.10 Android 首輪回饋

2026-11-15，使用者表示「目前測試起來體感ok」，並確認試玩平台為 Android 手機。記錄為手機實際試玩與整體手感的正向回饋，先保留目前能力與數值。

本次未指定手機型號、Android 版本、能力配置或遭遇，也未提供逐項操作與效能紀錄。能力是否形成不同打法仍待對照；接下來優先觀察排線、放手蓄勢與盯住強敵的差異，再評估三連戰。此回饋不新增實作範圍。

## 本次回饋與開發節奏

使用者表示「目前測試起來 OK」，並認可現階段以簡單、快速的 PoC 測試推進。記錄為原型的正向試玩回饋；本次未逐項提供設備、遊玩次數、成功／失敗流程或效能量測，不將各項驗收清單自動勾成通過。

目前刺蝟的方向性尖刺玩起來偏向射擊遊戲，使用者接受它作為其中一種攻擊方式。整體遊戲仍希望呈現不同動物的不同攻擊特色。

## v0.2 小熊試玩回饋

使用者表示，小熊因攻擊距離較近，操作要求較高；不過基礎攻擊力也較高，因此玩起來「還可以」。這是近距離風險與傷害回報初步可接受的回饋，後續仍可觀察接敵、退開及清群的感受，不視為最終平衡結論。本次僅記錄，未依此調整數值。

## v0.3 構築試玩回饋

使用者表示「散射＋反彈明顯體感更爽」。推測與怪物從四面八方來有關；穿透初期不明顯，可能要等後期怪物更多、血量更高且同方向有多個目標時才有感。另感覺反彈能取代穿透的一部分傷害用途。

記錄為使用者體感與待驗證的原因假設。開發端核對後確認兩者都有額外多目標命中的功能，反彈另有搜尋並轉向目標的便利；上一版各四次起始強化並不等強。固定靶群檢查可觀察到直線與包圍情境各自偏好的組合，但不能直接推論實戰平衡。

詳細規則、檢查結果與建議的陣形比較實驗見 [v0.3 回饋分析](build-comparison-poc-v0.3.md)。本次更新紀錄與分析工具，未改動遊戲數值或產出新版 APK。

## v0.4 陣形比較回饋與取捨

使用者覺得「反彈好像就可以了，穿透沒有特別亮眼的地方」。本輪暫時未建立穿透值得選擇的鮮明理由；不把這個感受擴張成所有情境的強弱結論。

近期保留散射＋反彈的清群方向，暫停穿透 A／B 及陣形比較，不列為近期必須深化的路線。既有實驗程式及 APK 保留，本次未改動遊戲。構築多樣性仍待驗證；下一次比較應以不同用途與玩家行為為起點，而非只增加額外命中的方式。詳見 [v0.4 收斂紀錄](formation-comparison-poc-v0.4.md)。

使用者希望未來加入家中的黑貓與約克夏。以下保留使用者描述的真實行為，作為後續角色個性、攻擊與動作設計的依據。

| 角色候選 | 使用者描述的特色 |
| --- | --- |
| 黑貓 | 抓人、咬人 |
| 約克夏 | 汪汪叫、咬人；高興時會繞著人轉圈圈 |

具體技能、升級、加入順序與製作階段尚未決定。設計時需讓牠們保有各自特色，並與既有角色形成不同玩法；不將所有行為直接定為攻擊技能。

後續決策更新：使用者已將第一版主角改為家中的黑貓，角色名為「奈奈」。奈奈優先進入完整角色設計；約克夏仍為未來候選。抓、咬保留為特色依據，具體攻擊及能力尚待設計。

## 後續討論與驗證入口

進度：F03 已開始 [v0.2 角色對照 PoC](animal-attacks-poc-v0.2.md)，由開發端先選小熊揮擊與刺蝟尖刺比較；程式與 APK 已完成，已收到上述小熊首輪操作回饋。黑貓與約克夏列為未來角色候選。F01、F02 保留後續階段逐步完善。

接續 [v0.3 構築比較 PoC](build-comparison-poc-v0.3.md) 與 [v0.4 陣形比較 PoC](formation-comparison-poc-v0.4.md) 均已收到回饋：散射＋反彈有正向爽感，穿透仍不亮眼。近期暫停這組比較，後續改以用途與玩家行為差異選擇實驗問題。

以下是可供下階段研究的提案，尚未選定實作內容或順序。

這些歷史提案改按 F04 排序；下一步先完成單一角色設計。

- **主題／故事：**先定玩家想保護、探索或達成什麼，以及動物、敵人與場地之間的關係，再決定故事需要多少篇幅、以什麼方式出現。
- **回饋：**優先評估受傷、重要命中、升級、危險提示等事件；釐清哪些值得震動，避免每發尖刺或每次擊殺都震動造成干擾。
- **角色差異：**下一個比較用角色可探索近距離揮擊、跳躍／衝撞、範圍噴流、地面區域或設置物等行為。具體動物、能力與輸入方式仍待選定，這些例子不等於正式角色名單。
- **判斷方式：**在相同敵人情境下，觀察玩家換角色後是否改變站位、瞄準、接敵時機或升級選擇，確認角色差異能反映在實際遊玩。

後續仍採「提出問題 → 小型 PoC → 試玩回饋 → 調整」的節奏；完整美術、故事與回饋系統依相應階段逐步收斂。
