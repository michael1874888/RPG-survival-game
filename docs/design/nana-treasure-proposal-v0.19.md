# 奈奈 v0.19：帶一件鈴鐺進下一局

**Status:** implemented · **Updated:** 2026-11-19。使用者已確認實作；規則仍須 Android 真人試玩，數值與重玩效果待驗證。

依據：[v0.18 試玩回饋](poc-feedback-and-followups.md#v018-分支試玩回饋2026-11-18)。保留 B 的兩條分支，下一輪優先驗證一件可帶回、可裝備的寶物。

## 1. 這版要回答什麼

玩家能描述雙發蓄勢適合一般戰況、回身追咬打守關者較輕鬆，願意嘗試另一條路，但兩條體驗過後，繼續開局的吸引力仍弱。這支持保留目前分支；尚不能推論分支平衡、勝率或長期重玩已成立。

本輪目標：**「我拿到一件能留下的東西，想帶進下一局，試出新的成長順序。」**

只做一件「回身鈴鐺」、一個裝備格，以及取得 → 保存 → 裝備 → 再出發的完整流程。沿用四段短局、敵人、經驗預算與攻擊操作。這版不做商店、貨幣、稀有度、隨機詞綴、強化等級或第二件實物寶物。

## 2. 玩家會走過的流程

| 時點 | 玩家看到及能做的事 | 作用 |
| --- | --- | --- |
| 尚未取得 | 森林短局準備畫面顯示「寶物：尚無」 | 不用先學一套收藏系統 |
| 首次完成第三段 | 戰利品出現回身鈴鐺並自動收取，段間卡片顯示「已收藏，下局可裝備」及效果 | 在進守關前留下戰果；本局能力不改變 |
| 本局結束 | 結算顯示新收藏，保留一般的再挑戰、更換開局與離開選項 | 觀察玩家是否主動繼續 |
| 再次準備 | 一格寶物可選「不裝備／回身鈴鐺」，首次預設不裝備，後續記住上次選擇；選擇 B 時可帶入 | 裝備是玩家自己的選擇 |
| 帶鈴鐺的下一局 | B 一級仍照常；第一次把 B 升到二級時，提早取得回身追咬 | 把熟悉效果提早納入本局規劃 |
| 試用結束 | 寶物永久保留，下一局仍可裝或卸下 | 觀察新鮮感過後是否仍想玩 |

第一次取得有明確卡片與簡短閃光，確認後回到段間流程，不增加戰鬥按鍵。第三段完成後的戰利品自動收取，避免為了測收藏而增加找地面小物的負擔。這是在測帶回與裝備；戰中冒險撿取本身另待後續討論。

從結算按再挑戰也要經過簡短的準備確認，能看見鈴鐺並自己選擇裝備；不將按鈕改成只提供「裝上再玩」，也不自動替玩家裝備。

## 3. 回身鈴鐺的效果與代價

裝備文字提案：**「B 升到二級時提前取得回身追咬；本局 B 的成形路線固定為追咬，最多存一發。」**

| 狀態 | B 成長 | 三級成形名額 |
| --- | --- | --- |
| 不裝鈴鐺 | B1 蓄勢 → B2 推開 → B3 選雙發或追咬 | 沿用目前規則 |
| 裝回身鈴鐺 | B1 蓄勢 → B2 推開＋提前追咬；B 到此完成 | 取得 B2 時視為已用掉本局唯一成形名額 |

1. 本輪鈴鐺限 **B 起手**使用。A／C 起手仍可遊玩及取得鈴鐺；切換至這兩種起手時，本局顯示「未裝備」，收藏不消失。
2. 玩家必須花一次正常升級選 B2；裝上不會在開局直接給推開或追咬。若延後選 B，效果也延後。
3. B2 取得後，追咬沿用 [v0.18 分支規則](nana-b-branch-playtest-v0.18.md)的數值與觸發方式。不另加傷害、蓄勢速度或第二次追咬。
4. 裝備代表本局選定追咬路線：不再提供 B3 卡片，不可同時取得雙發；A／C 也不能升三級。第二核心仍能加裝及升二級；裝鈴鐺時共通強化上限提高至三級，確保後期仍有三張合法候選。
5. 為避免先選 A／C 三級後再取得免費追咬，**裝備時就預留成形名額給 B**，從開局起排除 A／C 三級卡。B2 取得後顯示「追咬成形（鈴鐺）」，不把畫面數字冒充 B3。
6. 相較原本 B3 追咬，鈴鐺提早一個升級取得效果，也省下一次投資；多出的機會可用於第二核心或共通強化。這是明確的跨局收益，並非等強替換。其代價是本局提前固定路線，失去看局勢再選雙發或另一核心三級的彈性。
7. 卸下鈴鐺後，下一局恢復原有兩條 B3 分支與成形名額。裝備僅能在開局前改，局中不可切換。

這個處理避免兩個問題：B3 再提供一次已取得的追咬，以及追咬與雙發免費疊加成為全面優勢。剩餘升級候選仍必須維持三個不同的合法選項；若限制後出現不足，應先修候選規則，不能補送重複或無效升級。

## 4. 怎麼取得，失敗會留下什麼

- 尚未持有時，首次完成森林短局第三段 **保證取得一次**，不綁 B3 選擇、不要求擊敗守關者；一般能力比較及三連戰不掉落。本輪建議先用雙發走一次以延續 v0.18 對照，但不將此變成掉落條件。
- 若在第三段完成前死亡、逾時或退出，沒有取得。第三段完成並收取後，即使守關失敗、退出或關閉應用，鈴鐺仍保留。
- 取得時即寫入永久收藏，成功後才顯示「已收藏」；不等整局結算才保存。關閉後重開仍能看見，更新 APK 沿用同套件及資料時仍保留；解除安裝清除資料不保證保留。
- 存檔失敗時顯示「本次收藏未儲存」並提供重試；不將當次未落盤的取得標成永久成功，也不清空既有收藏。新存檔的安全替換失敗須保留上次有效版本。
- 已持有後不再掉第二個，不產生數量、出售、分解或補償貨幣。寶物不消耗，失敗不掉裝備。
- 首次裝備需主動選擇；後續保存玩家上次選擇。一般遊戲介面不提供清空收藏，開發測試可用獨立資料重跑首次取得，避免刪玩家存檔。

## 5. 怎麼判斷值得繼續

先讓玩家完成一次取得流程，再自由決定是否再開；不要在結算前提醒「記得再玩一局」。若第三段前就結束，這次只能觀察取得門檻，不能判收藏沒有吸引力。

| 觀察 | 要記什麼 | 可以判斷到哪裡 |
| --- | --- | --- |
| 第一次結算後 | 是否主動進準備、裝鈴鐺、開下一局；若有提醒，另行註記 | 是否產生首次試用的動機 |
| 裝備局 | 何時選 B2、節省的升級選什麼、是否在守關前使用追咬、能否說出這局的新安排 | 物品是否實際改變成長與操作 |
| 試用局結束後 | 自己繼續、卸裝對照、離開；先記行動，再問原因 | 新鮮感用過後是否仍有局內目標 |
| 後續回饋 | 先問「你現在最想做什麼，為什麼？」；再問是否期待其他寶物及想改哪種打法 | 期待更多收藏是意願訊號，尚非實際尋寶行為 |

只有一件寶物，不能真的測「追下一件」或跨日留存；不放假的可取得圖鑑、未實作掉落或進度條來製造期待。若玩家主動想找下一件，再規劃第二件可取得的實物，以行為驗證。

決策提案：

- **主動試裝，而且試用後能提出想繼續完成的打法／想要的寶物效果：**值得 review 第二件寶物及兩件之間的配裝取捨，仍先小規模。
- **只為看新效果再玩一次，之後又沒目標：**先整理收藏、戰鬥目標與成長回報的缺口，不直接擴充一大批寶物。
- **只因更容易通關而繼續：**記為永久戰力收益的正向回饋；需再區分喜歡變強還是喜歡收藏與配裝。
- **覺得裝備強制固定 B 不好玩，或過早追咬讓前段失去判斷：**先調鈴鐺的限制／時點；保留原有 B 分支。

單一玩家、少量局數用於決定下一個實驗，不推論群體留存或正式平衡。

## 6. 實作與驗收

1. 接通最小收藏存檔與準備畫面：取得、重開、裝卸、無資料舊版更新、讀寫失敗的保存行為可驗證。
2. 接第三段戰利品與鈴鐺的局內效果：在同樣候選種子和操作條件檢查提早追咬的時間、合法候選、成形名額及兩發上限，記錄永久收益對難度的影響。
3. 接段間／結算提示與觀察紀錄，回歸四段流程後匯出 v0.19 Android 測試版到既有 SSD 目錄；手機試玩驗證文字、存檔與動機。

驗收項目（自動檢查與手機實測分別判定）：

- [ ] 第三段前失敗不解鎖；第三段後失敗、退出、重開仍保留；重複取得不增加數量。
- [ ] 開局未裝備時完整保留 v0.18 B3 兩分支；新裝備不會自動啟用。
- [ ] 裝備時 B1 無追咬、B2 有追咬；不出 B3、A3、C3，仍有三個合法且不同的成長選項。
- [ ] B2 追咬效果、C 獵痕例外、死亡／失手清除、換段和重試均正確；沒有雙發與追咬疊加。
- [ ] 觀察紀錄含寶物取得、裝卸、開局配置、B2 生效、後續升級與結算後選擇，能按局串接；沒有把按鈕點擊當作完成下一局。
- [ ] Android 上取得、關閉重開、裝卸與同套件更新保留收藏；存檔失敗不覆蓋既有收藏。
- [ ] 真人能理解何時生效及路線代價，並能自行決定是否再玩；行動、提醒及主觀原因分別記錄。

## 7. 本輪已確認的設計取捨

本輪核准範圍為：**第三段保證帶回一件鈴鐺；永久保存與一格裝備；B2 提前追咬並固定本局成形路線；一輪取得、下一輪自由試用。**

最重要的取捨是「提早成形並省一次升級，但放棄本局其他三級核心路線」；裝備時允許共通強化升到三級，以確保後期有三張不同的合法選項。
